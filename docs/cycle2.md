# 사이클 2 구현 리스트

- 궁성 구현하기
  - 궁성 객체 구현 -> 궁성 좌표 집합, 좌표별 연결 관계 관리
    - 궁성 기물들 궁성 내에서 활동하도록 구현
    - 차, 포 '궁성 내에서' 대각선 이동도 가능하도록 구현
    - 졸 '궁성 내에서' 앞 대각선 이동 가능하도록 구현(뒤, 뒤대각선 불가)
- 왕 잡히면 게임 종료 구현
  - [ ] 기물 삭제 로직에서 왕인지 체크하도록
  - [ ] 왕이 맞다면 게임 상태를 종료로 변경
- 점수 계산 구현
  - [ ] 한은 기본적으로 1.5점 추가
  - [ ] 기물마다 점수 구현
  - [ ] 보드를 출력할 때, 실시간 점수를 항상 함께 출력
- 진행 상황 저장 구현
  - [ ] 게임 진행 상태, 보드 기물 상태, 턴을 저장 
    - 보드는 포지션과 기물들을 가진다.(보드-기물 1:N, 기물-위치 1:1 관계로 구현)
  - [ ] 게임 시작 시 '진행중' 인 게임이 있으면 기물과 턴 정보를 불러와서 기물 배치 후 진행
