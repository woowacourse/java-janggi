# java-janggi

장기 미션 저장소

# 🎲️ 구현할 기능 목록

## 1. 보드 초기화

- [x] 10 X 9 배열을 사용하여 장기판을 생성한다.
- [x] 전체 기물을 올바른 위치에 초기화한다.
    - [x] 한나라 기물이 장기판의 윗부분에 위치한다.

## 1-1. 진영 선택

- [x] 초나라 플레이어가 선공권을 갖는다.

## 2. 보드 출력

- [x] 장기판을 출력한다.

## 3. 이동 기물 입력

- [ ] 이동할 기물의 좌표를 입력받는다. (e.g. 3,4)
    - [ ] 검증: 형식에 맞지 않는 좌표 입력은 예외를 발생한다.

## 3-1. 기물 이동

- [ ] 검증: 장기판 범위를 초과한 좌표 입력은 예외를 발생한다.
- [ ] 검증: 기물이 존재하지 않는 좌표 입력은 예외를 발생한다.
- [ ] 검증: 상대 기물이 위치하는 좌표 입력은 예외를 발생한다.

- [ ] 보드가 좌표를 입력 받아 해당 기물 객체를 반환한다.
- [ ] 기물 이동 전략에 따라 이동 가능한 위치 좌표 목록을 계산한다.

## 3-2. 이동 가능 위치 좌표 목록 출력

- [ ] 이동 가능 위치 좌표 목록을 번호를 매겨 출력한다.

## 3-3. 이동 위치 좌표 입력

- [ ] 이동 가능 위치 좌표의 번호를 입력받는다.
    - [ ] 검증: 존재하지 않는 번호 입력은 예외를 발생한다.

## 3-4. 이동 진행 보드 적용

- [ ] 선택된 이동 위치 좌표에 기물을 이동시킨다.

## 4. 턴 교체

- [ ] 플레이어 턴을 교체한다.

2번으로 이동하여 게임을 반복한다.

## 5. 게임 종료

- [ ] 각 플레이어가 턴을 5회 진행 시, 게임이 종료된다.

# ♟️구현할 기물 기능 목록

## 졸

- [ ] 상/좌/우 3가지 방향으로 1 칸 이동한다.
- [ ] 이동 위치에 아군 기물이 있을 경우, 이동할 수 없다.

## 차

- [ ] 상/하/좌/우 4가지 방향으로 n 칸 이동 가능하다.
- [ ] 다른 기물을 뛰어넘을 수 없다.
- [ ] 이동 위치에 아군 기물이 있을 경우, 이동할 수 없다.

## 마

- [ ] 1차 이동: 상/하/좌/우 4가지 방향으로 1 칸 이동한다.
- [ ] 2차 이동: 1차 이동 후, 해당 방향의 대각선 방향으로 1 칸 추가로 이동한다.
- [ ] 1차 이동 위치에 다른 기물이 존재할 경우, 이동할 수 없다.
- [ ] 2차 이동 위치에 아군 기물이 있을 경우, 이동할 수 없다.

## 상

- [ ] 1차 이동: 상/하/좌/우 4가지 방향으로 1 칸 이동한다.

- [ ] 3차 이동: 2차 이동 후, 해당 대각선 방향으로 1 칸 추가로 이동한다.
- [ ] 1차 이동 위치에 다른 기물이 존재할 경우, 이동할 수 없다.
- [ ] 2차 이동 위치에 다른 기물이 존재할 경우, 이동할 수 없다.
- [ ] 3차 이동 위치에 아군 기물이 있을 경우, 이동할 수 없다.

## 포

- [ ] 포를 제외한 다른 정확히 한 개의 기물을 뛰어넘은 후, n 칸 이동 가능하다.
- [ ] 단, 포 끼리는 뛰어넘거나 잡아먹을 수 없다.
