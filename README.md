## 기능 목록

### 게임 로드 기능

- 이전에 종료된 게임이 존재하지 않는 경우, 자동으로 [나라 별 차림법 입력 기능](#나라-별-차림법-입력-기능)으로 이동합니다.
- 이전에 종료되지 않은 게임을 불러옵니다.

```angular2html
이전에 저장된 게임을 불러옵니다.
```

### 나라 별 차림법 입력 기능

- 나라 별로 차림법을 입력받습니다.
- 제공되는 차림법은 다음과 같습니다:
    - 안상 차림: 마 - 상 - 상 - 마
    - 바깥상 차림: 상 - 마 - 마 - 상
    - 왼상 차림: 상 - 마 - 상 - 마
    - 오른상 차림: 마 - 상 - 마 - 상
- 차림법 적용은 두 나라에 동일한 방식으로 화면을 기준으로 이루어집니다.

```angular2html
한나라의 차림법을 입력해주세요.
1. 안상 차림
2. 바깥상 차림
3. 왼상 차림
4. 오른상 차림
1
```

- **[예외 상황]**
    - 차림법 명령 번호가 `1` ~ `4` 범위가 아닌 경우

### 장기판 초기화 기능

- 입력받은 두 나라의 차림법을 기반으로 하여 장기판을 초기화합니다.
- 초기화된 장기판을 출력합니다.

```angular2html
두 나라 모두 '안상 차림'을 선택한 경우

１　２　３　４　５　６　７　８　９
1 車　馬　象　士　＊　士　象　馬　車
2 ＊　＊　＊　＊　漢　＊　＊　＊　＊
3 ＊　包　＊　＊　＊　＊　＊　包　＊
4 兵　＊　兵　＊　兵　＊　兵　＊　兵
5 ＊　＊　＊　＊　＊　＊　＊　＊　＊
6 ＊　＊　＊　＊　＊　＊　＊　＊　＊
7 卒　＊　卒　＊　卒　＊　卒　＊　卒
8 ＊　包　＊　＊　＊　＊　＊　包　＊
9 ＊　＊　＊　＊　楚　＊　＊　＊　＊
10 車　馬　象　士　＊　士　象　馬　車

```

### 기물 별 이동 기능

- 각 기물은 고유한 행마법을 가지고 있으며, 그 행마법은 다음과 같습니다.
    - 궁(漢 또는 楚)과 사(士): 궁성 내에서 1칸 이동할 수 있습니다.
    - 차(車): 직선 전후좌우로 장애물이 나올 때까지 이동할 수 있습니다. 또한, 궁성 안의 간선 이동이 가능합니다.
    - 포(包): 직선 전후좌우로 포를 제외한 다른 기물을 **반드시** 뛰어넘어 장애물이 나올 때까지 이동할 수 있습니다. 단, 적군 포를 잡을 수 없습니다.
      또한, 궁성 안의 간선 이동이 가능합니다.
    - 마(馬): 직선 전후좌우로 1칸 전진후 대각선으로 좌나 우로 1칸 이동할 수 있습니다.
    - 상(象): 직선 전후좌우로 1칸 전진후 대각선으로 좌나 우로 2칸 이동할 수 있습니다.
    - 병/졸(兵/卒): 직선 좌우로 1칸이나 상대 진영쪽으로 1칸 이동할 수 있습니다. 또한, 상대방의 궁성에 있는 경우 간선을 타고 대각선으로도 1칸 이동할 수
      있습니다.

### 게임 진행 기능

- 각 나라는 번갈아 가면서 자신의 턴을 진행하며, **한나라**부터 시작하게 됩니다.
- 각 나라는 자신의 턴에서 다음의 단계를 수행합니다.
    - 먼저, 움직일 기물의 위치를 `행,열` 형식으로 입력받습니다.
      ```angular2html
      한나라 차례입니다. 움직일 기물의 위치를 입력하세요. (형식: 행,열)
      4,1
      ```
    - 입력받은 위치 및 기물을 기반으로 하여 **이동 가능한 위치**를 계산하고 출력합니다.
        - 이동 가능한 위치는 청록색으로 표시됩니다.
    - 가고자 하는 위치를 `행,열` 형식으로 입력받습니다.
      ```angular2html
      선택한 기물의 목표 위치를 입력하세요. (형식: 행,열)
      4,2
      ```
    - 입력받은 위치로 기물을 이동시킵니다.
- 다음 나라의 턴으로 변경합니다.

### 게임 종료 기능

- 게임 진행 도중 어느 한 나라의 `장(漢 또는 楚)`이 잡힌 경우, 그 즉시 게임이 종료됩니다.
- 승리한 나라를 출력합니다.

## 구현 예정 기능

- 게임방 입장 기능 (게임 로드 기능을 교체)
    - 게임 시작 시, 불러올 게임을 숫자로 입력합니다.
  ```angular2html
  불러올 게임을 선택하세요. (최대 3개 저장 가능)
  1. 게임 1
  2. 게임 2
  0. 새 게임 생성
  ```
    - 기존 게임을 선택한 경우, 게임 상태를 불러옵니다.
  ```angular2html
  게임 1의 진행 상태를 불러옵니다.
  ```
    - 새 게임 생성을 선택한 경우, 게임을 새롭게 생성합니다.
  ```angular2html
  새 게임 생성을 선택하였습니다. 새로운 게임을 시작합니다.
  ```
- **[예외 상황]**
    - 예상치 못한 명령 번호가 입력된 경우
