# java-janggi

장기 미션 저장소

## 기물 종류 (초·한)

- 궁(楚·漢, General)
- 사(士·士, Guard)
- 마(马·馬, Horse)
- 상(象·象, Elephant)
- 졸, 병(卒·兵, Soldier)
- 포(包·包, Cannon)
- 차(车·車, Chariot)

## 기물 점수

- 차: 13점
- 포: 7점
- 마: 5점
- 상: 3점
- 사: 3점
- 졸/병: 2점
- 한은 1.5점 덤을 받아 시작한다. 

## 기능 명세서

### 1️⃣ 사이클1

- [x] 플레이어 2명의 이름을 입력받는 기능
    - [x] 초나라 → 한나라 순서로 입력을 받는다.
    - [x] 출력: 초나라 플레이어의 이름을 입력하세요(2~5자, 영어만 사용):
    - [x] 출력: 한나라 플레이어의 이름을 입력하세요(2~5자, 영어만 사용):
    - [x] 각 이름의 규칙을 검증한다. (2~5자, 영어만)
- [x] 보드 초기화하는 기능
    - [x] 초나라가 아래 좌표를 사용한다.
    - [x] 초나라 기물 좌표는 (전체 보드 길이 - 한나라 기물 좌표)로 설정
    - [x] 각 기물 타입은 List.of()를 사용해 초기 위치를 필드로 가진다.
- [x] 각 플레이어의 상차림을 입력받는 기능
    - [x] 출력: 초나라 플레이어가 사용할 상차림 번호를 입력하세요
      `1. 상마상마(象马象马) 2. 상마마상(象马马象) 3. 마상마상(马象马象) 4. 마상상마(马象象马) :`
        - [x] 초나라 숫자 입력 및 번호 검증
    - [x] 출력: 한나라 플레이어가 사용할 상차림 번호를 입력하세요
      `1. 상마상마(象馬象馬) 2. 상마마상(象馬馬象) 3. 마상마상(馬象馬象) 4. 마상상마(馬象象馬) :`
        - [x] 한나라 숫자 입력 및 번호 검증
    - [x] 입력받은 상차림으로 각 플레이어 상과 마 위치를 결정

### 2️⃣ 사이클2

- [x] 각 플레이어 턴 진행
    - [x] 현재 장기판을 출력한다.
        - [x] 초나라 기물을 파란색, 한나라 기물은 빨간색으로 출력한다.
    - [x] 플레이어가 가진 기물들의 이름과 좌표 목록을 출력한다.
        - [x] 출력: `이동할 기물을 선택하세요 1. 楚(2, 5)  2. 卒(2, 6)  3.  ~~~~`
    - [x] 이동할 기물의 번호를 입력받는 기능
        - [x] 제공된 기물 목록 번호 내의 범위인지 검증
    - [x] 선택한 기물의 이동할 좌표를 선택하는 기능
        - [x] 선택한 기물이 이동 가능한 좌표를 모두 계산한다.
            - [x] 이동 가능한 좌표가 없으면 기물을 다시 선택하도록 돌아간다.
        - [x] 출력: `이동할 좌표를 선택하세요: 1. (1, 2) 2. (2, 3) 3. ~~~`
        - [x] 이동할 좌표 번호 입력하는 기능
            - [x] 입력한 번호가 목록 내에 있는지 검증
        - [x] 해당 좌표로 이동
            - [x] 만약 해당 좌표에 상대 기물이 있으면, 상대 기물 삭제
    - [x] 이동을 완료하면 각 플레이어의 현재 점수를 표기한다.
- [x] 궁성 관련 행마법 로직 구현
    - [x] 궁
        - [x] 궁은 궁성 안에서만 움직일 수 있다.
    - [x] 사
        - [x] 사는 궁성 안에서만 움직일 수 있다.
    - [x] 차
        - [x] 궁성 내부에서는 대각선으로 이동할 수 있다.
        - [x] 궁성 대각선 경로 중간에 말이 있으면 지나갈 수 없다.
    - [x] 포
        - [x] 궁성 내부에서는 대각선으로 이동할 수 있다.
        - [x] 궁성 대각선 이동 시 가운데 말을 다리로 삼아야 한다.
        - [x] 궁성 대각선 이동 시 다리가 없으면 이동할 수 없다.
        - [x] 궁성 대각선 이동 시 다리가 포이면 이동할 수 없다.
    - [x] 졸/병
        - [x] 궁성 내부에서는 전진 방향으로 대각선 1칸 이동할 수 있다.
        - [x] 궁성 내부에서는 후퇴 방향 대각선 이동은 할 수 없다.
- [x] 게임 종료
    - [x] 상대방 궁을 잡으면 게임에서 승리한다.
    - [x] 게임이 끝나면 승리한 플레이어를 출력한다.
- [ ] DB 연동
    - [ ] DB 연동 및 Config 설정
    - [ ] 장기 게임 저장 기능
        - [ ] 매턴 종료마다 게임에 대한 정보 DB 저장
        - [ ] 이전에 플레이 하던 장기 게임을 재시작 하는 기능
    - [ ] (선택) 장기 게임방을 만들고 장기 게임방에 입장할 수 있는 기능 추가
