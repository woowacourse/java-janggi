# 기능 구현 목록

### (직접 해석한) 장기 규칙

1. 기물은 자신의 이동 규칙에 맞게 이동 가능
2. 도착 지점에 본인 팀의 기물이 존재하는 경우 이동 불가
3. 포는 상대방의 포를 넘어갈 수 없고, 도착지점에 포가 존재하는 경우 이동 불가
4. 궁성이 존재하지 않으므로 장, 사는 한 칸만 이동 가능
5. 장이 죽는 경우 게임 종료

### 입력

- 선공/후공 닉네임
- 상, 마 배치 선택 (1 - 상마상마, 2 - 마상마상, 3 - 마상상마, 4 - 상마마상)
- 기물 선택
    - 출발 위치
- 기물 이동
    - 도착 위치

### 출력

- 보드 출력

### 예외 상황

아래 예외 상황에 적절한 예외문을 출력하며, 게임을 계속 진행한다.

#### 닉네임

- 닉네임 형식에 어긋나는 경우
- 닉네임이 중복되는 경우

#### 상, 마 배치

- 말 배치 입력에서 1~4 이외의 입력이 들어오는 경우

#### 출발 좌표 입력

- 유효한 좌표가 아닌 경우(보드의 바깥쪽)
- 기물이 없는 경우
- 상대편 기물이 있는 경우

#### 도착 좌표 입력

- 유효한 좌표가 아닌 경우
- 기물의 고유 이동 규칙에 어긋나는 경우
- 도착지에 같은 팀 기물이 존재하는 경우
- 포를 제외한 기물 이동 시 이동 경로에 기물이 존재하는 경우
- 포가 이동 시
    - 이동 경로에 기물이 존재하지 않는 경우
    - 이동 경로에 기물이 두 개 이상 존재하는 경우
    - 이동 경로에 포가 존재하는 경우
    - 도착지에 포가 존재하는 경우

### 플레이어

- 플레이어 이름
    - 2~8글자로 설정 가능하다.
    - 영어, 한글, 숫자만 입력이 가능하다.
    - 공백이 들어가면 안된다.

### 게임 매니저

- 게임 상태

### 보드

- 기물 이동 가능 여부 판단
- 기물 이동
- 기물 위치 저장

### 보드 팩토리

- 배치를 입력받아 보드를 생성하는 정적 팩토리 메서드

### 포지션

- 좌표 저장
- 좌푯값 검증
    - row : 0~8
    - column : 0~9

### 경로

- 출발지 포지션, 목적지 포지션, 중간 지점 포지션 리스트를 저장

### 경로 기물

- 출발 기물 저장
- 목적지에 기물이 있다면 그 기물을 저장
- 중간 지점에 기물이 있따면 그 기물을 저장

### 기물

- 이동 규칙 저장
    - 이동 가능한 방향을 하드코딩
    - source, destination으로 판단

#### 경로 생성기

- 직진 경로 생성기
    - 출발지와 목적지를 입력하면 직진 경로를 생성한다.
- 일반 경로 생성기
    - 출발지와 목적지를 입력하면 하드코딩된 이동 방향을 토대로 경로를 생성한다.

#### 이동 전략

- 일반전략
    - 경로에 막히면 안된다.
- 포전략
    - 이동 기준(포 제외 말 넘기)
    - 잡히는 기준(포는 못 잡음)

### 팀(enum)

- CHO, HAN
