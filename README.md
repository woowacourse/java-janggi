# java-janggi

장기 미션 저장소

## 구현할 기능 목록

### 입력 기능

- [ ] 상차림을 입력받는다.
- [ ] 이동할 기물의 위치를 입력받는다.
- [ ] 기물을 이동시킬 위치를 입력받는다.

### 출력 기능

- [ ] 현재 장기판의 상황을 출력한다.
- [ ] 선택한 기물이 이동할 수 있는 지점을 모두 표시한다.

### 도메인 기능

- [x] 각 기물은 고유한 행마법에 의해 이동할 수 있어야 한다.
- [x] 적 기물이 있는 위치로 이동하면 해당 적 기물을 잡는다.
- [x] 본인 진영 기물만 움직일 수 있다.
- [x] 이동할 수 없는 지점으로 움직이려하면 예외를 던진다.
- [x] 각 진영은 교대로 기물을 이동한다.

#### 기물 초기 위치

- [x] 시작 위치가 고정된 기물들은 게임 시작 시 정해진 위치에 배치되어야 한다.
- [x] `상`과 `마`는 지정한 순서에 따른 위치에 배치되어야 한다.

## 용어 사전

| 용어 (영문)                  | 설명                                              |
|:-------------------------|:------------------------------------------------|
| **Row**                  | 장기판의 가로 선 (행)                                   |
| **File**                 | 장기판의 세로 선 (열)                                   |
| **Intersection**         | 가로선과 세로선이 만나서 생기는 격자점. 기물이 위치할 수 있는 곳           |
| **Side**                 | 진영. 초(CHO)와 한(HAN)으로 나뉨                         |
| **Piece**                | 장기판 위에 놓이는 모든 기물의 총칭                            |
| **Chariot**              | 차 (車). 전후좌우로 장애물이 없는 한 끝까지 이동 가능                |
| **Horse**                | 마 (馬). 날일자(日) 형태로 이동하며, 진행 방향의 첫 칸(멱)이 비어있어야 함  |
| **Elephant**             | 상 (象). 밭전자(田) 형태로 이동하며, 경로상의 모든 지점이 비어있어야 함     |
| **Guard**                | 사 (士). 궁성 안에서만 한 칸씩 이동하며 궁을 보좌함                 |
| **General**              | 궁 (장군). 궁성 안에서만 이동 가능한 왕                        |
| **Cannon**               | 포 (包). 다른 기물을 하나 넘어서 이동하거나 상대 기물을 취함            |
| **Soldier**              | 병(한), 졸(초). 앞으로 가거나 좌우로 한 칸씩 이동하며 후퇴 불가         |
| **Screen**               | `포`가 이동하거나 공격하기 위해 뛰어넘어야 하는 징검다리 기물             |
| **Wing**                 | 진. 상과 마가 배치되는 지역으로 좌진(`Left`)과 우진(`Right`)으로 나뉨 |
| **Palace**               | 궁성. '궁'과 '사'가 위치하며 그 안에서만 움직일 수 있는 중앙 3x3 구역    |
| **XxxMovement**          | (특정 기물의) 행마법                                    |
| **Path**                 | 기물이 목적지까지 도달하기 위해 거쳐야 하는 intersection들          |
| **Destination**          | `Path` 중 목적지                                    |
| **PassingIntersections** | `Path` 중 목적지를 제외한 나머지                           |
