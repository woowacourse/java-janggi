## **구현할 기능 목록**

### 입력 기능

- [x] 상차림을 입력받는다.
    - [x] [예외상황] 해당하지 않는 상차림을 입력한 경우, "[ERROR] 존재하지 않는 상차림입니다."를 출력하고 재입력 받는다.

- [x] 움직일 기물의 좌표를 입력받는다.
    - [x] [예외상황] 좌표 형식이 잘못된 경우, "[ERROR] 잘못된 좌표 형식입니다."를 출력하고 재입력 받는다.
    - [x] [예외상황] 좌표가 2개가 아닌 경우, "[ERROR] 좌표는 2개만 입력해 주세요."를 출력하고 재입력 받는다.
    - [x] [예외상황] x좌표와 y좌표의 범위가 잘못된 경우, "[ERROR] x좌표와 y좌표의 범위가 올바르지 않습니다."를 출력하고 재입력 받는다.
    - [x] [예외상황] 해당 좌표에 기물이 존재하지 않는 경우, "[ERROR] 해당 좌표에 기물이 존재하지 않습니다."를 출력하고 재입력 받는다.
    - [x] [예외상황] 해당 좌표의 기물이 나의 기물이 아닌 경우, "[ERROR] 본인 진영의 기물이 아닙니다."를 출력하고 재입력 받는다.

- [x] 움직이고 싶은 위치의 좌표를 입력받는다.
    - [x] [예외상황] 좌표 형식이 잘못된 경우, "[ERROR] 잘못된 좌표 형식입니다."를 출력하고 재입력 받는다.
    - [x] [예외상황] 좌표가 2개가 아닌 경우, "[ERROR] 좌표는 2개만 입력해 주세요."를 출력하고 재입력 받는다.
    - [x] [예외상황] x좌표와 y좌표의 범위가 잘못된 경우, "[ERROR] x좌표와 y좌표의 범위가 올바르지 않습니다."를 출력하고 재입력 받는다.
    - [x] [예외상황] 움질일 위치와 움직이고 싶은 위치가 동일한 경우, "[ERROR] 기물을 동일한 위치로 이동시킬 수 없습니다."를 출력하고 재입력 받는다.
    - [x] [예외상황] 해당 좌표에 이동할 수 없는 경우, 움직일 기물의 좌표부터 재입력 받는다.

### 보드 초기화 기능

- [x] 상차림 기능
    - [x] 왼상 차림 - 상마상마
    - [x] 오른상 차림 - 마상마상
    - [x] 안상 차림 - 마상상마
    - [x] 바깥상 차림 - 상마마상
- [x] 게임 시작 시 장기판과 전체 기물을 올바른 위치에 초기화한다.
    - [x] 각 플레이어가 선택한 상차림에 맞게 보드를 초기화한다.

### 기물 이동 경로 계산 기능

- [x] 기물의 출발지부터 도착지까지의 경로를 계산한다.

### 기물 이동 기능

- [x] 각 기물은 이동 규칙에 맞게 이동한다.
    - [x] 졸・병(卒·兵) - 좌, 우, 앞으로 이동
    - [x] 사(士) - 궁성 내부에서 1칸씩 이동(선따라 이동)
    - [x] 상(象) - 1칸 이동 후, 대각선 2칸
    - [x] 마(馬) - 1칸 이동 후, 대각선 1칸
    - [x] 포(包) - 기물을 이용해 뛰어넘어 이동 (포끼리는 뛰어 넘지도 먹지도 못함)
    - [x] 차(車) - 앞, 뒤, 좌, 우 직선으로 원하는 곳까지 이동 가능
    - [x] 궁(漢·楚) - 궁성 내부에서 1칸씩 이동(선따라 이동)

### 출력 기능

- [x] 현재 차례를 출력한다.

- [x] 장기판을 출력한다.
    - [x] 보드판은 고정되어 있기 때문에, 한나라의 초기 상차림만 반대로 한다.
