### 도메인 기능

- [ ] 각 기물은 고유한 행마법에 의해 이동할 수 있어야 한다.
- [ ] 적 기물이 있는 위치로 이동하면 해당 적 기물을 잡는다.
- [ ] 본인 진영 기물만 움직일 수 있다.
- [ ] 각 진영은 교대로 기물을 이동한다.

#### 기물 초기 위치

- [x] 시작 위치가 고정된 기물들은 게임 시작 시 정해진 위치에 배치되어야 한다.
- [x] `상`과 `마`는 지정한 순서에 따른 위치에 배치되어야 한다.
