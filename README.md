# 기능 명세서

---

## 기능

### 게임 초기화

- [x]  한나라가 위, 초나라를 아래로 위치시켜 보드를 초기화한다.

### 게임 진행

- [x]  초나라 선공, 한나라 후공으로 게임이 교대로 진행된다.
- [x]  입력받은 좌표와 각 기물의 행마법에 따라 기물을 이동시킨다.
- [x]  매 턴마다 현재 남아 있는 기물에 대한 점수를 표시한다.
- [x]  상대방의 궁(왕)을 잡으면 그 즉시 게임이 종료된다.
- [x]  궁을 잡을 수 있는 상태가 되면 '장군' 메시지를 출력한다.

### 기물 이동 규칙

| **기물** | **기본 이동 방식** | **궁성 내 특수 규칙** | **특징** |
| --- | --- | --- | --- |
| **궁(將/楚)** | 상하좌우 1칸 | 대각선 경로를 따라 1칸 이동 가능 | 궁성 밖으로 나갈 수 없음 |
| **사(士)** | 상하좌우 1칸 | 대각선 경로를 따라 1칸 이동 가능 | 궁성 밖으로 나갈 수 없음 |
| **차(車)** | 상하좌우 직선으로 거리 제한 없이 이동 | 궁성 내 대각선 경로가 있으면 대각선 이동 가능 | 경로에 다른 기물이 있으면 통과 불가 |
| **포(包)** | 다른 기물 하나를 뛰어넘어 직선 이동 | 궁성 내 대각선 경로에서 기물을 하나 넘어서 이동 | 포끼리 넘기/잡기 불가 |
| **마(馬)** | 직선 1칸 + 대각선 1칸 (일자 이동) | 해당 없음 | 이동 경로 중간(멱)이 막히면 이동 불가 |
| **상(象)** | 직선 1칸 + 대각선 2칸 (용자 이동) | 해당 없음 | 이동 경로 중간(멱)들이 막히면 이동 불가 |
| **졸/병(卒/兵)** | 앞 또는 옆으로 1칸 | 적군 궁성 내에서 대각선 앞 방향 이동 가능 | 후퇴 불가 |
- 마와 상을 제외한 모든 기물은 궁성 내 그어진 대각선 라인을 따라 이동할 수 있다.

### 게임 종료

- [x]  왕 피격: 어느 한 쪽의 궁(왕)이 잡히면 게임이 종료된다.
- [x]  점수 계산 규칙:
    - 차(車): 13점
    - 포(包): 7점
    - 마(馬): 5점
    - 사(士): 3점
    - 상(象): 3점
    - 졸/병(卒/兵): 2점
    - 후공 보정 점수: 한나라는 총점에 1.5점을 추가한다.

## DB

### 데이터 저장

- [x]  게임 내 기물 이동이 성공할 때마다 현재 보드 상태(게임 ID, 좌표, 기물 종류, 진영)를 DB에 저장한다.
- [x]  게임의 메타데이터(현재 차례(Turn), 게임 종료 여부, 점수)를 DB에 업데이트한다.

### 게임방 관리

- [x]  새 게임 시작 시 게임 ID, 생성 날짜 및 시간, 진행 상태, 현재 턴, 점수를 포함한 새로운 게임 레코드를 생성한다.
- [ ]  저장된 게임 목록을 조회한다.
- [ ]  특정 게임 ID를 지정하여 해당 게임 데이터를 DB에서 완전히 삭제한다.

### **목록 내 액션**

- [ ]  출력된 목록에서 특정 게임 ID를 입력받아 게임에 입장(재개)한다.
- [ ]  출력된 목록에서 특정 게임 ID를 입력받아 해당 게임을 삭제한다.

## 입력

- [x]  메뉴 번호를 입력받는다.

   ```java
   1. 새 게임 시작
   2. 게임 목록 보기
   3. 게임 종료
   메뉴를 선택하세요: 
   ```

- [ ]  게임 목록에서 입장하거나 삭제할 게임의 ID 입력받는다.

   ```java
   명령어를 입력하세요.
   입장: play [ID] / 삭제: delete [ID] / 이전 메뉴: back
   (예: play 1 혹은 delete 1 혹은 back)
   ```

- [x]  초나라가 기물을 선택하고 행마를 입력한다.

   ```java
   초나라 턴입니다. 이동할 기물의 좌표와 도착할 좌표를 입력하세요. (예 : (1, 2), (3, 3))
   ```

- [x]  한나라가 기물을 선택하고 행마를 입력한다.

   ```java
   한나라 턴입니다. 이동할 기물의 좌표와 도착할 좌표를 입력하세요. (예 : (1, 2), (3, 3))
   ```


## 출력

- [x]  게임 시작 멘트를 출력한다.

   ```java
   게임을 시작하겠습니다.
   ```

- [x]  보드판을 출력한다.

   ```java
      ０  １  ２  ３  ４  ５  ６  ７  ８ 
   0 [車][象][馬][士][　][士][象][馬][車]
   1 [　][　][　][　][漢][　][　][　][　]
   2 [　][包][　][　][　][　][　][包][　]
   3 [兵][　][兵][　][兵][　][兵][　][兵]
   4 [　][　][　][　][　][　][　][　][　]
   5 [　][　][　][　][　][　][　][　][　]
   6 [卒][　][卒][　][卒][　][卒][　][卒]
   7 [　][包][　][　][　][　][　][包][　]
   8 [　][　][　][　][楚][　][　][　][　]
   9 [車][象][馬][士][　][士][象][馬][車]
   ```

- [x]  각 진영 별로 현재 남아있는 기물의 총 점수를 출력한다.

   ```java
   [기물 점수]
   초나라 : 72.0점
   한나라 : 73.5점
   ```

- [x]  기물 이동 후 현재 보드 상황에 따라 장군 여부를 출력한다.

   ```java
   장군입니다! 기물을 움직여 궁을 살리세요.
   ```

- [x]  게임 종료 시 승리 팀과 최종 점수를 출력한다.

   ```java
   왕(궁)이 잡혔습니다! 초나라의 승리입니다.
   
   [최종 점수]
   초나라 : 72.0점
   한나라 : 73.5점
   ```

- [ ]  저장된 게임이 없을 경우 메시지를 출력한다.

   ```java
   저장된 게임이 없습니다.
   ```

- [ ]  메뉴 중 2번(게임 목록 보기) 선택 시 DB에 저장된 모든 게임 목록을 출력한다.

   ```java
   [저장된 게임 목록]
   ID: 1 | 생성일: 2024-04-14 19:30 | 상태: 진행중 | 순서: 초나라 | 초: 72.0 한: 73.5
   ID: 2 | 생성일: 2024-04-15 10:15 | 상태: 종료됨 | 순서: 한나라 | 초: 0.0 한: 73.5
   ```

- [ ]  게임 입장 성공 시 메시지를 출력한다.

   ```java
   게임을 이어서 진행합니다.
   ```

- [ ]  게임 삭제 성공 시 메시지를 출력한다.

   ```java
   게임이 삭제되었습니다.
   ```


## 유효성

### Input

- [x]  입력이 비어있는 경우

   ```java
   [ERROR] 입력값이 비어있습니다.
   ```

- [x]  쉼표를 포함하지 않은 경우

   ```java
   [ERROR] 쉼표(,)를 기준으로 입력하세요.
   ```

- [x]  숫자를 포함하지 않은 경우

   ```java
   [ERROR] 좌표는 숫자로 입력해야 합니다.
   ```

- [x]  입력된 숫자의 개수가 2가 아닌 경우

   ```java
   [ERROR] 좌표는 두 개의 숫자(예: 1, 2)로 입력해야 합니다.
   ```


### Position

- [x]  장기판의 x좌표 범위를 벗어난 경우

   ```java
   [ERROR] 장기판의 x좌표 범위를 벗어났습니다.
   ```

- [x]  장기판의 y좌표 범위를 벗어난 경우

   ```java
   [ERROR] 장기판의 y좌표 범위를 벗어났습니다.
   ```

- [x]  기물이 존재하지 않는 좌표인 경우

   ```java
   [ERROR] 존재하지 않는 좌표입니다.
   ```


### Move

- [x]  상대 팀의 기물을 이동하려 한 경우

   ```java
   [ERROR] 자신의 기물만 이동시킬 수 있습니다.
   ```

- [x]  기물이 이동할 수 없을 경우

   ```java
   [ERROR] 유효하지 않는 행마입니다.
   ```

- [x]  출발지에 이동할 기물이 없는 경우

   ```java
   [ERROR] 출발지에 이동할 기물이 없습니다.
   ```

- [x]  출발지와 목적지의 좌표가 같은 경우

   ```java
   [ERROR] 출발지와 목적지가 같을 수 없습니다.
   ```

- [x]  목적지에 위치한 기물이 아군인 경우

   ```java
   [ERROR] 목적지에 아군 기물이 위치하고 있습니다.
   ```


### Game

- [x]  게임 미종료 시 승자를 조회한 경우

   ```java
   [ERROR] 게임이 아직 종료되지 않아 승자를 확인할 수 없습니다.
   ```

- [x]  보드 위에 왕이 존재하지 않는 경우

   ```java
   [ERROR] 보드 위에 왕이 존재하지 않습니다.
   ```


### DB

- [ ]  입력 형식이 `명령어 + ID` 조합이 아닌 경우

   ```java
   [ERROR] 올바른 명령어 형식이 아닙니다. (예: play 1)
   ```

- [ ]  존재하지 않는 ID를 입력했을 경우

   ```java
   [ERROR] 해당 ID의 게임이 존재하지 않습니다.
   ```

- [ ]  종료된 게임에 입장하려고 할 경우

   ```java
   [ERROR] 종료된 게임에는 입장할 수 없습니다. (목록에서 삭제만 가능합니다.)
   ```
