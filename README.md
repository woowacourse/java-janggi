# java-janggi

장기 미션 저장소

# 기능 목록

### 게임 상태
- [ ] 누구의 차례인지 알 수 있다.
- [ ] 게임이 진행 가능한지 알 수 있다.
- [ ] 게임 승패를 가릴 수 있다.

### 장기 게임
- [ ] 입력값이 장기판 범위 내인지 확인한다.
- [ ] 선택 가능한 기물인지 확인한다.
  - [ ] 빈 칸(기물)좌표가 아니어야 한다.
  - [ ] 턴에 맞는 기물 좌표여야 한다.

### 장기판
- [x] 아군 기물들을 반환할 수 있다.
- [x] 적군 기물들을 반환할 수 있다.
- [x] 장기판 위 기물 이동 가능 여부를 확인한다.
- [ ] 빈 칸(기물)들을 반환할 수 있다.

---

### 기물 -> 이동 전략, 기물 속성

### 기물 속성
- [x] 기물 이름 `ex. 車`
- [x] 소속팀

### 이동 전략
- [x] 입력받은 위치 값(목적지)으로 이동 가능 여부를 반환할 수 있다.
  - [x] General(장군)
  - [x] Guard(사)
  - [x] Soldier(초/한 각각 생성)
  - [x] Horse(마)
  - [x] Elephant(상)
  - [x] Chariot(차)
  - [x] Cannon(포)

- [x] 입력받은 위치들(아군, 적군)이 이동경로에 포함되는지 여부를 반환할 수 있다.
  - 목적지만을 확인하는 기물(졸, 장, 사)는 `false` 반환 - [x] General(장군)
  - [x] Horse(마)
  - [x] Elephant(상)
  - [x] Chariot(차)
  - [x] Cannon(포)
