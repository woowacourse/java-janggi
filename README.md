### 무엇을 개발하는가?

- 장기 게임 도메인을 개발한다.
    - 출력은 요구사항에 없다.
    - Domain 에서 View 의 책임은 완전히 배재한다.
    - 출력은 사이클2 때 필요 하에 구현한다.
- 궁성 규칙(궁성 구간의 대각선, 궁성 구간에서 달라지는 이동 규칙)은 구현하지 않는다.
    - 사이클 2에서 구현한다.

### 기능명세서

- [ ] 궁의 이동을 구현한다
    - [ ] `전`,`후`,`좌`,`우`로 한 칸 이동한다.
- [ ] 사의 이동을 구현한다
    - [ ] `전`,`후`,`좌`,`우`로 한 칸 이동한다.
- [ ] 졸의 이동을 구현한다
    - [ ] `전`,`좌`,`우`로 한 칸 이동한다.
- [ ] 마의 이동을 구현한다
    - [ ] `전`/`후`/`좌`/`우`-`우대각선`으로 한 칸 이동한다.
    - [ ] `전`/`후`/`좌`/`우`-`좌대각선`으로 한 칸 이동한다.
    - [ ] 이동 경로에 다른 기물이 있으면 안 된다.
- [ ] 상의 이동을 구현한다
    - [ ] `전`/`후`/`좌`/`우`-`우대각선`-`우대각선`으로 한 칸 이동한다.
    - [ ] `전`/`후`/`좌`/`우`-`좌대각선`-`좌대각선`으로 한 칸 이동한다.
    - [ ] 이동 경로에 다른 기물이 있으면 안 된다.
- [ ] 포의 이동을 구현한다
    - [ ] 기물 1개를 넘어서 `전`,`후`,`좌`,`우`로 n칸 이동한다.
    - [ ] 이동 경로에 기물이 1개 있어야 한다.
    - [ ] 이동 경로에 상대의 포가 있으면 안 된다.
    - [x] 도착지에 상대의 포가 있으면 안 된다.
    - [ ] 이동 경로에 다른 기물이 있으면 안 된다.
- [ ] 기물의 위치를 초기화한다.
    - [ ] 한나라의 궁1 졸5 사2 마2 상2 차2 포2 를 초기화 한다.
    - [ ] 초나라의 궁1 졸5 사2 마2 상2 차2 포2 를 초기화 한다.
- [x] 기물의 진영을 구현한다.
    - [x] 한나라인지 확인한다.
    - [x] 초나라인지 확인한다.
- [x] 기물의 위치정보를 관리할 수 있다.
    - [x] 행을 구현한다.
    - [x] 열을 구현한다.
- [x] 같은 진영의 기물은 공격할 수 없다.
