# java-janggi
장기 미션 저장소

## 목표
1. 빠르게 개발하고 PR한다.
2. 하나의 기능에 10분 이상 고민하지 않기.
3. 싸우지 않기.

## 🎯 상세 기능 구현 목록
### ⌨️ 입력 (InputView)
- [ ]사용자로부터 이동 명령 입력 받기
    - [ ] 현재 위치와 이동할 위치 입력 안내 메시지 출력 (예: 1,1 1,2)
    - [ ] 사용자 입력 받기
    - [ ] 입력값 앞뒤 공백 제거

### 장기 게임 (JanggiGame)
- [ ] 장기 게임 흐름 관리
  - [ ] 게임 턴 관리
  
- [ ] 초기 장기판 셋업 (각 기물들을 정해진 초기 Point에 배치)

### ✉️ 도메인 (Domain)
#### 좌표 (Point)
- [ ] X, Y 좌표를 묶어 Value Object로 관리
- [ ] 입력된 좌표가 장기판 규격(X: 0~8, Y: 0~9) 내에 있는지 검증

#### 장기판 (Board)
- [ ] Map<Point, Piece> 형태로 전체 보드 상태 관리
- [ ] 출발지 좌표에 실제로 기물이 존재하는지 검증
- [ ] 도착지 좌표에 아군 기물이 있는지 검증 (이동 불가)
- [ ] 기물(Piece)이 반환한 이동 경로 상에 다른 기물(장애물)이 있는지 최종 검증 (길막힘 판별)
- [ ] 검증 통과 시 보드 상태 업데이트 (기물 이동)
- [ ] 도착지에 적군 기물이 있다면 맵에서 제거 (포획 처리)

#### 기물 공통 (Piece - 움직임 전략 패턴)
- [ ] 기물의 소속 팀(한/초) 반환
- [ ] 출발지와 목적지 사이의 '이론적인 이동 경로(좌표 List)' 계산 및 반환

#### 개별 기물 이동 전략 (Piece 구현체들)
- [ ] 차(Cha): 가로/세로 직선 경로 좌표 반환
- [ ] 포(Pho): 가로/세로 직선 경로를 반환하되, 반드시 하나의 기물을 뛰어넘는 조건 고려
- [ ] 마(Ma): 일자 이동 후 대각선 이동 경로 좌표 반환 (중간 경로 좌표 포함)
- [ ] 상(Sang): 일자 이동 후 대각선 2칸 이동 경로 좌표 반환 (중간 경로 좌표 포함)
- [ ] 장(Jang) / 사(Sa) / 졸(Jol) 전진 1칸 또는 좌우 1칸 이동하는 좌표 반환 (후퇴 불가)

#### 턴 상태 (GameTurn - 상태 패턴)
- [ ] 공통: 현재 턴의 팀과 움직이려는 기물의 소속 팀이 일치하는지 검증
- [ ] HanTurn: 한나라 턴 로직 수행 후 초나라 턴으로 상태 전환
- [ ] ChoTurn: 초나라 턴 로직 수행 후 한나라 턴으로 상태 전환
- [ ] FinishedGame: 상대방의 '장(Jang)'이 잡혔을 때의 상태. 추가적인 이동 명령 거부

### 📤 출력 (OutputView)
#### 게임 진행 상태 출력
- [ ] 게임 시작 안내 메시지 출력
- [ ] 매 턴마다 현재 누구의 턴인지 출력
- [ ] 매 턴마다 이동 결과가 반영된 현재 장기판의 상태를 시각적으로 출력

#### 게임 종료 출력
- [ ] 승리 팀 안내 및 게임 종료 메시지 출력 

#### 에러 출력
- [ ] 예외 상황 발생 시 에러 문구 출력 (반드시 [ERROR]로 시작)
