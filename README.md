# 기능 구현 목록

## 입력

- 선공/후공 닉네임
- 상, 마 배치 선택 (1 - 상마상마, 2 - 마상마상, 3 - 마상상마, 4 - 상마마상)
- 기물 선택
    - 출발 위치
- 기물 이동
    - 도착 위치
- 게임 모드 선택 
  - 새 게임 또는 저장된 게임 불러오기

## 게임 매니저

- 게임 상태
- 턴 관리
- 기물 포획 여부 확인

## 보드

- 배치를 입력받은 정적 팩토리 메서드
- 기물 이동
- 기물 위치 저장

## 기물

- 이동 규칙 저장
    - 이동 가능한 방향을 하드코딩
    - source, destination으로 판단

### 전략

- 일반전략
    - 경로에 막히면 안된다.
- 포전략
    - 이동 기준(포 제외 말 넘기)
    - 잡히는 기준(포는 못 잡음)

## 포지션

- 좌표 저장
- 좌푯값 검증
    - row 0-9, col 0-8

## 팀(enum)

- CHO, HAN

## 예외 상황

- 닉네임이 빈 문자열인 경우
- 닉네임 중복 입력
- 말 배치 입력에서 1~4 이외의 입력이 들어오는 경우
- 유효하지 않은 좌표(보드의 바깥쪽)
- 선택 좌표에
    - 기물이 없을 때
    - 상대편 기물이 있을 때
- 도착 좌표가 유효한 좌표가 아닐 때

## 출력

- 보드를 출력한다.

## 데이터베이스 스키마

### game 테이블
```sql
CREATE TABLE game (
    game_id BIGINT AUTO_INCREMENT PRIMARY KEY,
    cho_name VARCHAR(50) NOT NULL,              -- 선공 플레이어명
    han_name VARCHAR(50) NOT NULL,              -- 후공 플레이어명
    current_turn VARCHAR(10) NOT NULL,          -- 현재 차례 (CHO, HAN)
    status VARCHAR(20) NOT NULL,                -- 게임 상태 (PROGRESS, CHO_WIN, HAN_WIN)
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### board 테이블
```sql
CREATE TABLE board (
    game_id BIGINT NOT NULL,
    row_idx INT NOT NULL,                       -- 행 좌표 (0~9)
    col_idx INT NOT NULL,                       -- 열 좌표 (0~8)
    team VARCHAR(10) NOT NULL,                  -- 기물 팀 (CHO, HAN)
    piece_type VARCHAR(10) NOT NULL,            -- 기물 종류
    PRIMARY KEY (game_id, row_idx, col_idx),
    FOREIGN KEY (game_id) REFERENCES game(game_id) ON DELETE CASCADE
);
```
