# Java-Janggi

## 장기 미션 저장소

### 과제 진행 요구 사항

첫 시작 시 장기의 보드판과 각 기물을 구현하라.

#### 장기 기획서

- 1단계에서는 장기 기물과 보드 초기화를 구현한다.
- 개발을 시작하기 전에 어떤 기능을 구현해야 하는지 정리한다.
- 궁(宮) 또는 궁성(宮城)의 영역을 고려한다.
    - 궁 기물과 사 기물은 궁성 내에서만 이동할 수 있다.
    - 궁성 내 꼭짓점과 중앙에서는 대각선 이동이 가능하다.
- 게임 승리 조건
    - 궁 기물을 먼저 잡으면 점수에 상관없이 승리한다.
    - 사용자가 게임 종료 조건을 입력하면 남은 기물의 점수로 승패를 판단한다.

---

## 기능 구현

### 장기

- [ ] 왕이 잡혔거나 게임 시작 후 15분이 지났을 때 게임을 종료한다.
    - [x] 왕을 잡았다면 잡은 쪽이 승리한다.
    - [ ] 게임 시작 후 15분이 지나면 남은 기물로 승패를 판단한다.

### 기물들

- [x] 기물을 초기화한다.
- [x] 어떤 좌표에 기물이 존재하는지 확인한다.

### 기물 (Unit)

- [x] 기물이 갈 수 있는 경로를 모두 계산한다.
    - [x] **궁**: 궁성 내 1번. (외부 이동 불가)
    - [x] **사**: 궁성 내 1번. (외부 이동 불가)
    - [x] **졸**: 직진(좌, 우, 상) 1번. 
    - [x] **마**: 직진(좌, 우, 상, 하) 1번 후 대각선 이동 1번.
    - [x] **차**: 직진(좌, 우, 상, 하)만 가능하다.
    - [x] **포**: 무조건 기물을 한 칸 점프해야 하며, 직진만 가능하다.
    - [x] **상**: 직진(좌, 우, 상, 하) 1번 후 대각선 이동 2번.

### 기물 타입

- [ ] 게임이 종료됐을 때 남은 기물의 점수 총합으로 점수를 계산한다.

### 궁성

- [x] 궁성의 네 꼭짓점과 중앙에서는 궁성 내 대각선으로 이동 가능하다.

``` plaintext
한나라 궁성
[(3,0),(4,0),(5,0)]
[(3,1),(4,1),(5,1)]
[(3,2),(4,2),(5,2)]

초나라 궁성
[(3,7),(4,7),(5,7)]
[(3,8),(4,8),(5,8)]
[(3,9),(4,9),(5,9)]
```

### 좌표

- [x] 좌표가 보드를 넘는지 판단한다.

## 참고

### 기물 별 대표 문자

``` plaintext
궁 (將, 帥)  : K
졸, 병 (卒, 兵) : A
사 (士, 仕)  : S
마 (馬)  : H
차 (車)  : C
포 (包)  : B
상 (象)  : E
```

### 그 외

- 어느 팀의 기물인지는 문자의 색상으로 구분한다
    - 빨간색: 한나라
    - 파란색: 초나라
