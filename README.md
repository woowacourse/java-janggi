# ♟️ java-janggi

## ✏️ 용어 정리
| 용어              | 설명                                                                                  |
| --------------- |-------------------------------------------------------------------------------------|
| Board           | 장기 게임이 진행되는 판을 의미한다.                                                                |
| Piece           | 장기판 위에 놓이는 말을 의미한다. 궁(King), 차(Cha), 포(Pho), 마(Ma), 상(Sang, 사(Sa), 쫄/병(Byeong)이 있다. |
| Blank           | 장기판에서 말이 놓여 있지 않은 빈 칸을 의미한다.                                                        |
| Team            | 초나라, 한나라와 같은 진영을 의미한다.                                                              |
| PieceType       | 장기 말의 종류(타입)를 나타낸다.                                                                 |
| PieceFactory    | `PieceType`에 따라 적절한 `Piece` 구현체를 생성하는 역할을 한다.                                       |
| Position        | x, y 좌표를 가지며, 장기판 위의 위치를 나타낸다.                                                      |
| deltaX / deltaY | 두 좌표 간의 x축 / y축 방향 차이를 의미한다.                                                        |
| Path            | 여러 개의 `Position`으로 이루어진 이동 경로를 나타내는 일급 컬렉션이다.                                       |

## 📄기능 명세
- [x] 게임 모드를 선택한다
  - [x] 기존의 게임 정보를 가져올지, 새로운 게임을 시작할지 입력한다.
  - [x] 기존의 게임 정보를 가져온다면, 해당 게임의 id를 입력한다.
- [x] 장기판을 구현한다.
    - [x] 장기판의 올바른 위치에 모든 기물들을 위치시킨다.
    - [x] 콘솔 기준 아래 쪽에 초나라를, 위 쪽에 한나라를 위치시킨다.
    - [x] 각 나라의 점수는 모든 기물들의 점수의 합이며, 초나라는 한나라보다 1.5점을 더 가지고 시작한다.(한나라: 72점, 초나라: 73.5점)
- [x] 각 기물들의 규칙을 구현한다.
    - [x] 궁의 이동 규칙을 정의한다.
      - [x] 네 방향(상/하/좌/우) 또는 궁성 대각선으로 한 칸 이동 가능하다.
      - [x] 궁성 내부에서만 이동 가능하다.
    - [x] 차의 이동 규칙을 정의한다.
      - [x] 네 방향(상/하/좌/우) 또는 궁성 대각선으로 n 칸(다른 기물 또는 벽에 막힐 때 까지)이동 가능하다.
    - [x] 포의 이동 규칙을 정의한다.
      - [x] 네 방향(상/하/좌/우)또는 궁성 대각선으로 n 칸(하나의 말을 뛰어 넘어야)이동 가능하다.
      - [x] 포끼리는 서로 넘거나 잡을 수 없다.
    - [x] 마의 이동 규칙을 정의한다.
      - [x] 날 일자 형태로 이동한다.
      - [x] 이동 경로 사이에 다른 말이 있을 경우 이동할 수 없다.
    - [x] 상의 이동 규칙을 정의한다.
      - [x] 쓸 용자 형태로 이동한다.
      - [x] 이동 경로 사이에 다른 말이 있을 경우 이동할 수 없다.
    - [x] 사의 이동 규칙을 정의한다.
      - [x] 네 방향(상/하/좌/우)또는 궁성 대각선으로 한 칸 이동 가능하다.
      - [x] 궁성 내부에서만 이동 가능하다.
    - [x] 쫄/병의 이동 규칙을 정의한다.
      - [x] 세 방향(상/좌/우)으로 한 칸 이동 가능하다.
