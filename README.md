# ✅ 구현할 기능 목록

## 게임 준비

### 마상 배치 선택하기
1P, 2P 순서로 마상 배치를 선택한다
- [ ] 안내 메시지: `(1 or 2)P 마상 배치를 선택해주세요.`
- [ ] 선택지: `1. 마상상마 2. 마상마상 3. 상마마상 4. 상마상마`
- [ ] 입력 형태: `1`, `2`, `3`, `4`

### 보드 초기화
선택한 마상 배치에 따라 기물을 배치한다
- [ ] 기본 배치 (한국식 장기)
  - 장·將: 궁 중앙 (col 4, row 1/8)
  - 사·士: 장 양옆 (col 3·5, row 0/9)
  - 차·車: 양 끝 (col 0·8, row 0/9)
  - 포·包: (col 1·7, row 2/7)
  - 졸·卒: 5개 (col 0·2·4·6·8, row 3/6)
  - 마·馬, 상·象: 마상 배치 선택에 따라 결정

## 게임 진행

### 턴 시작
- [ ] 초나라 선공, 한나라 후공
- [ ] 턴인 나라를 아래로, 상대 나라를 위로 출력한다
  - 행 순회 방향만 바꾼다 (내부 좌표·열 고정)
  - 행 번호는 보드 왼쪽, 열 번호는 보드 아래에 표시

### 기물 선택
- [ ] 턴인 나라만 자기 기물을 선택할 수 있다
- [ ] 기물 선택: `x y` 입력
  - 자기 나라 기물이 아니면 예외
- [ ] `q` 입력 시 기물 선택 취소

### 기물 이동
- [ ] 이동할 좌표: `x y` 입력 (절대 좌표 기준, col 0~8 / row 0~9)
  - 보드 밖이면 예외
  - 기물의 이동 전략에 없는 좌표면 예외
  - 경로가 막혀 있으면 예외
- [ ] 이동 후 다음 턴으로 교대

## 도메인

### Position
- 보드 위의 좌표 (row 0~9, col 0~8)
- 인스턴스를 미리 생성해 캐싱 → 같은 좌표는 항상 동일 객체 (`==` 비교 가능)
- 보드 범위 밖 좌표는 생성 불가 (예외 발생)

### Path
- 기물 하나의 이동 경로: 경유지 목록(`route`) + 목적지(`destination`)
- 이동 검증 시 경유지에 다른 기물이 있는지 확인하는 데 사용

### Board
- `Map<Position, Piece>`로 보드 상태 관리
- 기물 이동 흐름
  1. 해당 기물의 이동 가능한 Path 목록 조회
  2. 입력 목적지와 일치하는 Path 선택
  3. 경유지에 기물이 있는지 확인 (`canPassRoute`)
  4. 목적지 기물 잡기 가능 여부 확인 (`canCatch`)

### 기물 (Piece)

#### MoveStrategy 인터페이스
- 현재 위치에서 이동 가능한 모든 `Path` 반환
- 기물마다 전략 구현체를 가짐 (전략 패턴)

#### Piece 추상 클래스
- `canPassRoute`: 경유지 기물 목록을 받아 통과 가능 여부 반환
- `canCatch`: 목적지 기물을 받아 잡기 가능 여부 반환
- 포(Cannon)는 경유지에 기물이 정확히 1개 있어야 이동 가능, 포끼리는 잡기 불가

#### FormationStrategy 인터페이스
- 마상 배치 선택에 따라 마·상 위치가 달라짐 (전략 패턴)
- 4가지 구현체: 마상상마 / 마상마상 / 상마마상 / 상마상마

#### 기물 목록
- 장 (General) · 사 (Advisor)
- 차 (Chariot) · 포 (Cannon)
- 마 (Horse) · 상 (Elephant)
- 병/졸 (Soldier)
