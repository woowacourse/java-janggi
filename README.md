### 이동 규칙

공통 규칙

- 보드판을 벗어날 수 없다.
- 본인 진영의 말만 이동 시킬 수 있다.
- 상대 진영의 말이 있는 칸으로 이동하면 포획할 수 있다.
- 본인 진영의 말이 있는 칸으로 이동할 수 없다.

### 필요한 메시지 (행동)

- 플레이어들이 번갈아가며 각 기물들을 이동하라 JanggiGame
- 한쪽 진영의 말을 이동하라 (시작위치 → 도착위치) Player
- 기물을 이동시켜라 (시작위치 → 도착위치) Board
- 시작 위치의 기물을 도착위치로 움직일 수 있는지 알려줘 Piece

# 사이클 2

## 기능 요구사항

### 궁성 영역 구현
- 궁성 영역 좌표
  - (3,4),(3,5),(3,6)
  - (2,4),(2,5),(2,6)
  - (1,4),(1,5),(1,6)
- 궁, 사는 궁성 내부에서만 이동할 수 있으며 궁성을 벗어날 수 없다.
- 궁성 내 대각선 경로가 연결된 위치에 있는 기물은 대각선으로 이동할 수 있다.
  - 궁성 대각선 이동 규칙은 궁, 사, 차, 포, 졸에 적용한다.
  - 상과 마는 궁성 여부와 관계없이 기존 이동 규칙만 따른다.
- 차와 포는 궁성 내 대각선 경로를 따라 이동할 수 있다.
  - 차와 포가 궁성 내 대각선 경로를 이용해 이동하는 경우, 목적지는 반드시 궁성 내부여야 한다.

### 게임 종료조건
- 궁이 잡히는 경우
- 어느 한 진영이 장군 상태가 5번 반복될 경우 -> `빅장` 이라고 함
  - 점수를 계산하여 승패 판단

### 점수계산 (빅장 시)
- 후수(한)가 1.5점을 핸디캡으로 받고 시작
- 남아 있는 기물의 점수를 계산
- 기물의 점수
  - 차: 13점
  - 포: 7점
  - 마: 5점
  - 상: 3점
  - 사: 3점
  - 졸: 2점
  - 궁: 0점

### DB 적용

장기 게임을 한 번의 실행으로 끝내지 않고, 진행 중인 상태를 저장하고 다시 불러오기 위해 DB를 적용

현재 DB에는 다음 정보를 저장

- `game` 테이블
  - 게임의 고유번호
  - 게임의 상태(`WAITING_HAN_PLACEMENT`, `WAITING_CHO_PLACEMENT`, `IN_PROGRESS`, `FINISHED`)
  - 현재 턴
  - 초/한 장군 횟수
  - 생성 시간
![game_table_schema.png](game_table_schema.png)

- `board` 테이블
  - 기물의 고유번호
  - 기물 종류
  - 진영
  - 현재 위치 (x, y)
  - 어떤 게임에 속한 기물인지에 대한 game_id
![board_table_schema.png](board_table_schema.png)

#### 저장 시점
- 저장된 게임이 없어 새로운 게임을 만들 때
- 기물이 움직였을 때
- 초 or 한 이 장군상태가 되었을 때
- 턴이 넘어갔을 때
- 진행 상태가 변경될 때
  - 초기 상태 -> 한 진영 상차림 대기 상태
  - 한 진영이 상차림을 마쳤을 때 -> 초 진영 상차림 대기 상태
  - 초 진영이 상차림을 마쳤을 때 -> 게임 진행 상태
  - 게임이 끝났을 때 -> 게임 종료 상태
