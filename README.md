장기 미션 저장소

## 💡 주요 게임 규칙

### 대국 규칙

- [x] 초가 선수자, 한이 후수자
- [x] 후수자가 먼저 장기판 초기화 전략 선택
- [x] 선수자부터 기물 이동

### 기물 이동 규칙

- **궁, 사**
    - [x] 궁성을 벗어날 수 없음
    - [x] 뛰어넘기 불가
    - [x] 시작 위치 고정
    - [x] **궁성 영역:** 앞/옆/뒤 또는 궁성의 대각선 경로로 1칸 이동 가능
- **상**
    - [x] 앞/옆/뒤 1칸 + 대각선 2칸
    - [x] 뛰어넘기 불가
    - [x] 마와 위치 변경 가능
- **마**
    - [x] 앞/옆/뒤 1칸 + 대각선 1칸
    - [x] 뛰어넘기 불가
    - [x] 상과 시작 위치 변경 가능
- **차**
    - [x] 앞/옆/뒤 원하는 만큼 이동
    - [x] 뛰어넘기 불가
    - [x] 시작 위치 고정
    - [x] **궁성 영역:** 궁성의 대각선 경로로 원하는 만큼 이동 가능
- **포**
    - [x] 앞/옆/뒤 원하는 만큼 이동
    - [x] 포를 제외한 기물을 1개 뛰어넘어야만 이동
    - [x] 시작 위치 고정
    - [x] **궁성 영역:** 궁성의 대각선 경로로 원하는 만큼 이동 가능 (뛰어넘기 규칙 동일)
- **졸/병**
    - [x] 각 진영 기준 앞/옆으로만 1칸 전진
    - [x] 뛰어넘기 불가
    - [x] 시작 위치 고정
    - [x] **궁성 영역:** 궁성의 대각선 경로로 1칸 전진 가능

## 🚀 기능 요구 사항

### 게임 시작

- [ ] 애플리케이션 시작 시, 진행 중인 장기 게임 데이터가 존재하는지 확인한다.
    - [ ] 저장된 게임이 있다면, 이전 상태(보드판 정보, 현재 턴 등)를 불러와 대국을 이어간다.
    - [ ] 저장된 게임이 없다면, 새로운 대국을 시작하기 위해 보드 초기화 단계를 진행한다.

### 보드 초기화

- [x] 진영별 장기판 초기화 전략을 번호로 입력받는다.
    - 상마마상, 상마상마, 마상마상, 마상상마 중 전략 선택
    - [x] 사용자 입력값 유효성 검사
        - [x] 공백인 경우 예외 처리
        - [x] 숫자가 아닌 문자일 경우 예외 처리
        - [x] 정수 범위를 벗어난 경우 예외 처리
    - [x] 도메인 규칙 검증
        - [x] 입력값이 선택지 범위에 포함되지 않는 경우 예외 처리
- [x] 양 진영의 전략이 반영된 장기판 상태를 출력한다.
- [ ] 보드판의 상태(보드판 위 기물 배치)와 플레이 차례 정보를 저장한다.

### 기물 이동

- [x] 이동할 기물의 위치와 이동할 위치를 사용자로부터 입력받는다.
    - [x] 사용자 입력값 유효성 검사
        - [x] 공백인 경우 예외 처리
        - [x] `,` 로 구분된 좌표 형식이 아닌 경우 예외 처리
        - [x] 좌표값이 숫자가 아닌 경우 예외 처리
        - [x] 좌표값이 정수 범위를 벗어난 경우 예외 처리
    - [x] 도메인 규칙 검증
        - [x] 좌표값이 보드판의 범위를 벗어난 경우 예외 처리
        - [x] 해당 좌표에 이동시키고자 하는 기물이 존재하지 않는 경우 예외 처리
- [x] 기물을 이동시킨다.
    - [x] 도메인 규칙 검증
        - [x] 기물 규칙에 따라 이동할 위치에 도달할 수 없는 경우 예외 처리
    - [x] 이동할 위치의 기존 기물은 제거된다.
- [x] 이동이 반영된 장기판 상태를 출력한다.
- [ ] 보드판의 상태(보드판 위 기물 배치)와 플레이 차례 정보를 저장한다.

### 점수 계산

- [x] 보드판 위에 남아있는 기물별 점수를 합산해 진영별 총점수를 계산한다.
    - 초는 72점, 한은 73.5점으로 시작    
      > 단판 점수제 대국시에는 후수자(漢)는 선수자(楚)로부터 1.5점의 덤을 받는다.
    - 기물별 점수
        - **차:** 13점
        - **포:** 7점
        - **마:** 5점
        - **상:** 3점
        - **사:** 3점
        - **졸/병:** 2점
- [x] 매 턴 보드판이 출력될 때마다 양 진영의 점수를 함께 출력한다.

### 게임 종료

- [x] 궁이 잡히면 게임이 종료된다.
- [ ] 빅장(무승부)을 부르는 경우 게임이 종료된다.
    - [ ] 기물 총점이 각각 30점 미만인 경우에만 빅장 가능
    - [ ] 궁으로 상대의 기물을 취하면서 빅장이 되는 경우 빅장 불가
    - [ ] 궁빅, 만년장 중 궁빅 상황만 빅장 가능 상황으로 간주
      - 궁빅: 궁끼리 마주보며 그 사이에 아무 기물도 없는 상태
    - [ ] 매 턴 이동 완료 후 빅장 조건을 검사해, 선언 가능한 상황이면 사용자로부터 의사를 입력받는다.
        - [ ] 사용자 입력값 유효성 검사
          - [ ] 공백인 경우 예외 처리
          - [ ] Y 또는 N이 아닌 문자일 경우 예외 처리
        - [ ] `Y` 입력 시: 무승부로 게임 즉시 종료
        - [ ] `N` 입력 시: 빅장을 부르지 않고 다음 턴으로 정상 진행
- [x] 게임이 종료되면 승리 진영(또는 무승부)과 양 팀의 최종 점수를 출력한다.
- [ ] 게임 정보를 삭제한다.
