### 1.1단계 - 보드 초기화
1. Enum에 기물들의 초기 위치를 나열한다. (마,상 제외)
2. 마, 상의 배치는 Factory를 통해서 생성되도록 Enum에 저장해둔다.
3. 사용자에게 마,상의 위치를 입력 받는다.
4. Factory를 통해 마상 배치를 읽어온다.
5. 1번과 4번을 합쳐서 Board 도메인 객체를 생성한다. 

### 1.2단계 - 기물 이동
1)추상 클래스 : 기물(Piece)
- 필드 : String 이름, String 진영 
- 메서드 :List<Position> 이동규칙에_의한_모든_좌표_반환(Position 현재위치):

2)구현체 : 차, 마, 상, 사, 장, 포, 졸
각 기물 구현체들은 이동규칙을 소유함
→ 겹치는 규칙은 인터페이스로 구현

포 : 1) 앞에 있니 + 앞에 있는게 포니? 2) 두 번째 뭐 있니? + 뭐 있는게 포니? → 두 번째 이후 좌표 삭제, 3) 도착지에 같은 팀이니?
차 : 1) 앞에 있니 + 앞에 있는게 적군이니? 2) 도착지에 같은 팀이니?

마 : 1) 상하좌우 있니? 2) 도착지에 같은 팀이니?
상 : 1) 상하좌우 있니? 2) 상하좌우 + 대각선 있니? 3) 도착지에 같은 팀이니?

졸 : 1) 상좌우 있니? 2) 도착지에 같은 팀이니?

장 , 사 : 1) 상하좌우 있니? 2) 도착지에 같은 팀이니?
