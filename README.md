# :sparkling_heart: java-janggi 프로젝트 소개

웹 백엔드 7기 레벨1 장기 미션을 구현한 프로젝트입니다.

# :dart: 구현 기능 목록

## :rocket: 게임 시작

- [x] 게임시작 문구 출력

```
장기 게임을 시작하겠습니다!
```

## :rocket: 기물 배치

- [x] 초와 한의 초기 배치를 입력받을 수 있다.
    ```
    초의 초기 배치를 선택해주세요.
    1. 왼상(상마상마)
    2. 오른상(마상마상)
    3. 안상(마상상마)
    4. 바깥상(상마마상)
    2
    
    한의 초기 배치를 선택해주세요.
    1. 왼상(상마상마)
    2. 오른상(마상마상)
    3. 안상(마상상마)
    4. 바깥상(상마마상)
    1
    ```
- [x] 초의 마와 상의 초기배치를 할 수 있다.
    - 왼상 : 상마상마
    - 오른상 : 마상마상
    - 안상 : 마상상마
    - 바깥상 : 상마마상
- [x] 한의 마와 상의 초기배치를 할 수 있다.
    - 왼상 : 상마상마
    - 오른상 : 마상마상
    - 안상 : 마상상마
    - 바깥상 : 상마마상
- [x] 초와 한의 나머지 말을 초기배치를 할 수 있다.

  ![janggi_batch.png](/image/janggi_batch.png)

- [x] 초기 장기판을 출력할 수 있다.

   ```
    ５口 口 口 口 口 口 口 口 口
    ６졸 口 졸 口 졸 口 졸 口 졸

    ８口 口 口 口 궁 口 口 口 口
    ９차 마 상 사 口 사 상 마 차
    ```

## :rocket: 장기 시작

- [ ] 플레이 시작 문구 출력

    ```
    게임을 시작합니다!
    초나라 먼저 시작
    ```

## :rocket: 턴 진행

- [ ] 이번 턴에 수행할 행동 선택
    ```
    초의 턴입니다. 이번턴에 진행할 행동을 정해주세요!
    1. 기물 움직이기
    2. 한수 쉬어주기
    3. 게임 종료하기
    ```
- [x] 초을 선수로 한과 번갈아가며 턴을 반복할 수 있다.

## :rocket: 기물 이동

- [x] 초을 선수로 한과 번갈아가며 턴을 반복할 수 있다.

    ```
    이동할 장기말의 좌표 입력해주세요.
    0,1
    장기말의 좌표를 입력해주세요
    0,2
    ```

    - [x] 예외처리 - 좌표가 장기판의 범위를 벗어난 경우

    ```
    [ERROR] x좌표는 0~8, y좌표는 0~9 사이로 입력해주세요.
    ```

    - [x] 예외처리 - 이동할 장기말이 입력된 좌표에 없는 경우

    ```
    [ERROR] 해당 위치에 이동할 말이 존재하지 않습니다.
    ```
    - [x] 예외처리 - 장기말의 이동 규칙에 어긋난 경우

    ```
    [ERROR] 장기말의 이동 규칙을 확인해주세요.
    ```

    - [x] 예외처리 - 장애물로 인해 이동이 불가능한 위치인 경우

    ```
    [ERROR] 장애물로 인해 이동이 불가능합니다.
    ```

- [ ] 각 장기말 별로 이동을 구현할 수 있다.
    - [x] 궁
        - [x] 8방향으로 1칸씩 이동
        - [x] 궁안에서만 움직일 수 있음
    - [x] 사
        - [x] 8방향으로 1칸씩 이동
        - [x] 궁안에서만 움직일 수 있음
    - [ ] 차
        - [x] 동서남북 방향으로 끝까지 이동 가능
        - [x] 장애물을 넘지 못함
        - [ ] 궁안에서 대각선을 타고 이동 가능
    - [ ] 포
        - [x] 동서남북 방향으로 끝까지 이동 가능
        - [x] 혼자서는 움직일 수 없음
        - [x] 장애물이 있어야지 넘어서 이동 가능
        - [x] 포는 포를 잡을 수 없음
        - [x] 포는 서로의 장애물이 될 수 없음
        - [ ] 궁안에서 대각선을 타고 이동 가능
    - [x] 마
        - [x] 동사남북 방향으로 1칸이동 후 대각선을 1칸이동
        - [x] 장애물은 넘지 못한다.
        - [x] 궁안에서는 첫번째 움짐임에서는 대각선 이동 불가능
    - [x] 상
        - [x] 동사남북 방향으로 1칸 이동 후 같은 방향의 대각선으로 2칸 이동
        - [x] 궁안에서는 첫번째 움짐임에서는 대각선 이동 불가능
    - [x] 졸
        - [x] 앞과 양옆으로 1칸씩 이동 가능
        - [x] 뒤로는 이동 불가능
        - [x] 궁안에서 대각선 이동 가능
    - [x] 병
        - [x] 앞과 양옆으로 1칸씩 이동 가능
        - [x] 뒤로는 이동 불가능
        - [x] 궁안에서 대각선 이동 가능

- [ ] 목적지에 상대 장기말이 있을 경우 잡을 수 있다.
- [ ] 이동후 장군 여부를 판단할 수 있다.

- [ ] 기물 이동 후의 게임상태 출력
    - [ ] 각 진영의 점수 출력
      ```
      초의 점수 : 20점
      한의 점수 : 20.5점
      ```
    - [x] 장기판 출력
      ```
        ０ １ ２ ３ ４ ５ ６ ７ ８ㅇ
      ０차 마 상 사 口 사 상 마 차
      １口 口 口 口 궁 口 口 口 口
      ２口 포 口 口 口 口 口 포 口
      ３졸 口 졸 口 졸 口 졸 口 졸
      ４口 口 口 口 口 口 口 口 口
      ５口 口 口 口 口 口 口 口 口
      ６졸 口 졸 口 졸 口 졸 口 졸
      ７口 포 口 口 口 口 口 포 口
      ８口 口 口 口 궁 口 口 口 口
      ９차 마 상 사 口 사 상 마 차
      ```
    - [ ] 장군 여부 출력
      ```
      초의 장군입니다!
      한의 장군입니다!
      ```

## :rocket: 게임 종료

- [ ] 게임 종료 조건
    - [ ] 상대방의 궁을 잡으면 자동으로 종료
    - [ ] 턴 진행중에 게임 종료선언을 할 경우

- [ ] 승패 결정
    - [ ] 상대방의 궁을 잡으면 승리
    - [ ] 궁을 잡히면 패배
    - [ ] 게임을 중간에 그만둘 경우 점수로 승패 결정

- [ ] 게임 종료 문구를 출력할 수 있다.
    ```
    게임이 종료되었습니다!
    ```
- [ ] 승패를 원인과 함께 출력할 수 있다.
    ```
    궁을 잡았기 때문에 한의 승리입니다.
    ```
    ```
    점수가 더 높기 때문에 한의 승리입니다.
    ```
