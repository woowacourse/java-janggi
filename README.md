# java-janggi

장기 미션 저장소

## 기능 요구 사항

- [ ]  보드를 초기화한다.
- [ ]  기물을 이동한다.
    - [ ]  어느 위치의 기물을 어디로 이동할지 선택한다.
    - [ ]  기물의 도착지까지 이동 경로를 파악한다.
        - [ ]  `IllegalArgumentException` - 도착지까지 갈 수 없는 경우
    - [ ]  이동 경로로 실제 이동이 가능한지 파악한다.
        - [ ]  `IllegalArgumentException`  - 경로 상 기물이 존재해 ,갈 수 없는 경우
        - [ ]  `IllegalArgumentException` - 도착지에 같은 편 기물이 존재하는 경우
    - [ ]  보드에서 기물을 이동한다.
        - [ ]  이동한 위치에 상대편 기물이 있으면, 해당 기물을 탈락시킨다.
