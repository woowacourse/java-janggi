# ✅ 구현할 기능 목록

## 게임 준비

### 게임 옵션 선택하기
```
1. 게임 입장
2. 게임 삭제
3. 게임 종료
옵션을 선택해주세요.
```


## 게임 입장

```
1번방 | [CHO차례] 진행여부: 게임 종료
2번방 | [CHO차례] 진행여부: 진행 중
어느 방에 입장하시겠습니까? 새 게임 참여는 0을 입력해주세요.
```


## 게임 삭제
```
1번방 | [CHO차례] 진행여부: 게임 종료
2번방 | [CHO차례] 진행여부: 진행 중
어느 방을 삭제하시겠습니까? 종료된 게임만 삭제할 수 있습니다. 뒤로 가기는 0을 입력해주세요.
```
사용자가 종료된 게임을 삭제할 수 있다


## 게임 진행

### 게임 시작
###$ 마상 배치 선택하기
1P, 2P 순서로 마상 배치를 선택한다
- [x] 안내 메시지: `(1 or 2)P 마상 배치를 선택해주세요.`
- [x] 선택지: `1. 마상상마 2. 마상마상 3. 상마마상 4. 상마상마`
- [x] 입력 형태: `1`, `2`, `3`, `4`

#### 보드 초기화
선택한 마상 배치에 따라 기물을 배치한다
- [x] 기본 배치 (한국식 장기)
  - 장·將: 궁 중앙 (col 4, row 1/8)
  - 사·士: 장 양옆 (col 3·5, row 0/9)
  - 차·車: 양 끝 (col 0·8, row 0/9)
  - 포·包: (col 1·7, row 2/7)
  - 졸·卒: 5개 (col 0·2·4·6·8, row 3/6)
  - 마·馬, 상·象: 마상 배치 선택에 따라 결정

### 턴 시작
- [x] 초나라 선공, 한나라 후공
- [x] 턴인 나라를 아래로, 상대 나라를 위로 출력한다
  - 행 순회 방향만 바꾼다 (내부 좌표·열 고정)
  - 행 번호는 보드 왼쪽, 열 번호는 보드 아래에 표시

### 기물 선택
- [x] 턴인 나라만 자기 기물을 선택할 수 있다
- [x] 기물 선택: `x y` 입력
  - 자기 나라 기물이 아니면 예외
- [x] `q` 입력 시 기물 선택 취소

### 기물 이동
- [x] 이동할 좌표: `x y` 입력 (절대 좌표 기준, col 0~8 / row 0~9)
  - 보드 밖이면 예외
  - 기물의 이동 전략에 없는 좌표면 예외
  - 경로가 막혀 있으면 예외
- [x] 이동 후 다음 턴으로 교대


## 게임 종료
- [x] Give Up: 플레이어가 항복할 경우 패배 처리 후 게임이 종료된다
- [x] Draw: 플레이어가 상대방에게 무승부 요청을 한다
  - [x] 상대방이 제안을 받으면 양 플레이어의 점수를 비교해서 승/무/패를 판정한다
  - [x] 제안을 받지 않을 경우 게임을 이어간다
- [x] Checkmate: 왕이 잡힐 시 잡힌 플레이어는 패배 처리되고 게임이 종료된다

## 도메인

### Janggi (장기)
- 게임의 전체적인 흐름을 관리하는 **애그리거트 루트**입니다.
- `Board`와 `GameState`를 조합하여 기물 이동, 기권, 무승부 등의 게임 액션을 수행합니다.

### GameState (게임 상태)
- 상태 패턴(State Pattern)을 적용하여 게임의 흐름을 관리합니다.
- 현재 누구의 턴인지(`ChoTurn`, `HanTurn`), 게임이 종료되었는지(`Finished`, `GiveUp`, `Draw`, `Checkmate`)에 따라 다른 행동을 정의합니다.

### Board (보드)
- 10x9 크기의 장기판을 `Map<Position, Piece>` 형태로 관리합니다.
- 기물의 초기 배치(차림), 이동 유효성 검증, 점수 계산 등을 담당합니다.

### Camp (진영)
- 초(CHO)와 한(HAN) 두 진영을 나타내며, 각 진영의 전진 방향과 초기 배치 기준(Baseline) 정보를 가집니다.

### Position (위치)
- 장기판 위의 좌표(Row 0~9, Col 0~8)를 나타냅니다.
- **정적 팩토리 메서드와 캐싱**을 사용하여 동일한 좌표에 대해 항상 같은 인스턴스를 반환하도록 최적화했습니다.
- 궁성(Palace) 내 위치 여부와 대각선 이동 가능 여부를 판단하는 로직을 포함합니다.

### Path (경로)
- 기물이 한 번의 이동으로 거치는 경로(`route`)와 최종 목적지(`destination`)를 포함합니다.
- 이동 경로상에 장애물이 있는지 확인하는 검증 로직에서 활용됩니다.

### Piece (기물)
- 모든 장기 기물의 공통 속성과 행위를 정의한 추상 클래스입니다.
- **MoveStrategy (이동 전략)**: 기물마다 고유한 이동 로직을 전략 패턴으로 분리하여 구현했습니다.
- **FormationStrategy (차림 전략)**: '마상상마', '상마마상' 등 사용자의 선택에 따른 초기 기물 배치 로직을 관리합니다.
- **기물 종류**: 장(General), 사(Advisor), 차(Chariot), 포(Cannon), 마(Horse), 상(Elephant), 졸/병(Soldier)
- 각 기물은 자신의 점수 정보와 진영(Camp) 정보를 가집니다.
