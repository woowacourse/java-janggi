# java-janggi

장기 미션 저장소

# 기능 목록

### 게임 상태
- [x] 누구의 차례인지 알 수 있다.
- [x] 게임이 진행 가능한지 알 수 있다.
- [x] 게임 승패를 가릴 수 있다.
  - `장군`이 죽으면 게임이 종료된다.

### 장기 게임
- [x] 입력값이 장기판 범위 내인지 확인한다.
- [x] 선택 가능한 기물인지 확인한다.
  - [x] 빈 칸(기물)좌표가 아니어야 한다.
  - [x] 턴에 맞는 기물 좌표여야 한다.
- [x] 선택한 기물이 목적지에 이동할 수 있다.

### 장기판
- [x] 아군 기물들을 반환할 수 있다.
- [x] 적군 기물들을 반환할 수 있다.
- [x] 장기판 위 기물 이동 가능 여부를 확인한다.
- [x] 빈 칸(기물)들을 반환할 수 있다.
- [x] 기물을 이동시킬 수 있다.

---

### 기물 -> 이동 전략, 기물 속성

### 기물 속성
- [x] 기물 이름 `ex. 車`
- [x] 소속팀

### 이동 전략
- [x] 입력받은 위치 값(목적지)으로 이동 가능 여부를 반환할 수 있다.
  - [x] General(장군)
  - [x] Guard(사)
  - [x] Soldier(초/한 각각 생성)
  - [x] Horse(마)
  - [x] Elephant(상)
  - [x] Chariot(차)
  - [x] Cannon(포)

- [x] 입력받은 위치들(아군, 적군)이 이동경로에 포함되는지 여부를 반환할 수 있다.
  - 목적지만을 확인하는 기물(졸, 장, 사)는 `false` 반환 - [x] General(장군)
  - [x] Horse(마)
  - [x] Elephant(상)
  - [x] Chariot(차)
  - [x] Cannon(포)

---

### 궁성 영역
- [x] `3 * 3` 형태로 초나라(Green), 한나라(Red) 하나 씩 궁성이 있다.
  - 궁성의 영역 위치는 각 팀의 '장군'에 위치한다. (궁성 영역 가운데 위치에 장군이 존재.)
  - [x] 궁성의 양 끝 모서리 4곳은 가운데로 대각성 이동이 가능하다.
  - [x] 궁성의 가운데는 양 끝 모서리로 대각선 이동이 가능하다.
- [x] 기물 `장군`과 `사`는 궁성 범위 안에서만 움직일 수 있다.
- `마, 상`을 제외한 나머지 기물은 궁성의 이동 규칙을 따를 수 있다. (궁성 내 대각선 이동 가능)
  - [x] 장군/사
  - [x] 졸
  - [x] 차
  - [x] 포

---

### 점수 계산
- [x] 각 기물마다 점수가 있다.
  - 차: 13점
  - 포: 7점
  - 마: 5점
  - 상: 3점 
  - 사: 3점 
  - 졸: 2점
  - 장군: 0점
  - 후수(레드팀/한나라) 1.5점
- [x] 각 팀별 현재 남아 있는 기물에 대한 점수를 계산한다.
