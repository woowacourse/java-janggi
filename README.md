# java-janggi

장기 미션 저장소

## 우리가 정한 규칙

- 플레이어마다 총 시간이 한정되어 있고, 타임 아웃 시 판정패 (사이클2)

- 기물 종류 (초·한)
    - 궁(楚·漢, General)
    - 사(士·士, Guard)
    - 마(马·馬, Horse)
    - 상(象·象, Elephant)
    - 졸, 병(卒·兵, Soldier)
    - 포(包·包, Cannon)
    - 차(车·車, Chariot)

## 기능 명세서

### 1️⃣ 사이클1

- [x] 플레이어 2명의 이름을 입력받는 기능
    - [x] 초나라 → 한나라 순서로 입력을 받는다.
    - [x] 출력: 초나라 플레이어의 이름을 입력하세요(2~5자, 영어만 사용):
    - [x] 출력: 한나라 플레이어의 이름을 입력하세요(2~5자, 영어만 사용):
    - [x] 각 이름의 규칙을 검증한다. (2~5자, 영어만)
- [x] 보드 초기화하는 기능
    - [x] 초나라가 아래 좌표를 사용한다.
    - [x] 초나라 기물 좌표는 (전체 보드 길이 - 한나라 기물 좌표)로 설정
    - [x] 각 기물 타입은 List.of()를 사용해 초기 위치를 필드로 가진다.
- [x] 각 플레이어의 상차림을 입력받는 기능
    - [x] 출력: 초나라 플레이어가 사용할 상차림 번호를 입력하세요
      `1. 상마상마(象马象马) 2. 상마마상(象马马象) 3. 마상마상(马象马象) 4. 마상상마(马象象马) :`
        - [x] 초나라 숫자 입력 및 번호 검증
    - [x] 출력: 한나라 플레이어가 사용할 상차림 번호를 입력하세요
      `1. 상마상마(象馬象馬) 2. 상마마상(象馬馬象) 3. 마상마상(馬象馬象) 4. 마상상마(馬象象馬) :`
        - [x] 한나라 숫자 입력 및 번호 검증
    - [x] 입력받은 상차림으로 각 플레이어 상과 마 위치를 결정

### 2️⃣ 사이클2

- [ ] 각 플레이어 턴 진행
    - [x] 현재 장기판을 출력한다.
        - [x] 초나라(파란색), 한나라(빨간색), 좌표 출력
    - [ ] 플레이어의 기물들을 출력하는 기능
        - [ ] 출력: 이동할 기물을 선택하세요 1. 楚(2, 5)  2. 卒(2, 6)  3.  ~~~~
    - [ ] 이동할 기물의 번호를 입력받는 기능
        - [ ] 제공된 기물 목록 번호 내의 범위인지 검증
    - [ ] 선택한 기물의 이동할 좌표를 선택하는 기능
        - [ ] 선택한 기물이 이동 가능한 좌표를 모두 계산한다.
            - [ ] 이동 가능한 좌표가 없으면 기물을 다시 선택하도록 돌아간다.
        - [ ] 출력: 이동할 좌표를 선택하세요: 1. (1, 2) 2. (2, 3) 3. ~~~
        - [ ] 이동할 좌표 번호 입력하는 기능
            - [ ] 입력한 번호가 목록 내에 있는지 검증
        - [ ] 해당 좌표로 이동
            - [ ] 만약 해당 좌표에 상대 기물이 있으면, 상대 기물 삭제
