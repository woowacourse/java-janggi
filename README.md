## 무엇을 개발하는가?

- 장기판을 초기화한다.
- 각 진영은 상차림(상/마 조합)을 선택할 수 있다.
- 장기 기물의 이동 규칙을 구현한다.
- 턴에 따라 기물을 이동시키고, 보드 상태를 관리한다.
- 현재 장기판 상태를 출력한다.
- (추가) 궁성 영역을 포함한 장기 규칙을 구현한다.
- (추가) 왕이 잡히면 게임을 종료한다.
- (추가) 현재 남아 있는 기물을 기준으로 점수를 계산한다.
- (추가) 애플리케이션을 재시작하더라도 이전 게임을 다시 불러올 수 있다.
- (추가) 원하는 게임 메뉴를 선택할 수 있다. (게임로그재생, 새게임, 기존게임)

## DB 관련 추가 기능
- [x] 장기 게임방 생성 (`gameDao` save / `BoardPieceDao` saveAll)
- [x] 가장 최근에 생성된 게임 목록 10개 출력 (`GameDao` findTop10OrderByCreatedAtDesc)
- [x] 사용자의 gameId 입력을 받아, 해당 게임방 입장 (`GameDao` findById)
  - [x] 끝난 게임을 고른 경우 예외 처리
- [x] 게임 상태 변화 시 turn, status 만 수정해서 쿼리로 업데이트 (`GameDao` updateState)
- [x] 기물 이동시, 좌표값만 수정해서 쿼리로 업데이트 (`BoardPieceDao` updatePosition)
- [x] 기물이 다른 기물에게 잡힐 시, 해당 기물 삭제 (`BoardPieceDao` deleteByGameIdAndPosition)
- [x] 마지막으로 둔 수를 저장한다. (`MoveHistoryDao` save)
- [ ] 마지막으로 둔 수를 무를 수 있다. (`MoveHistoryDao` findLastMoveOrderByGameId, deleteById)
- [x] 게임의 플레이 로그를 순서대로 실행할 수 있다. (`MoveHistoryDao` findAllByGameIdOrderByMoveOrderAsc)

## 기능 명세

### 궁
- [x] `전`, `후`, `좌`, `우`로 한 칸 이동할 수 있다.
- [x] `궁성 대각선` 위에 있을 경우, 대각선 방향으로 한 칸 이동할 수 있다.
- [x] 이동 목적지가 궁성 내부가 아니면 이동할 수 없다.

### 사
- [x] `전`, `후`, `좌`, `우`로 한 칸 이동할 수 있다.
- [x] `궁성 대각선` 위에 있을 경우, 대각선 방향으로 한 칸 이동할 수 있다.
- [x] 이동 목적지가 궁성 내부가 아니면 이동할 수 없다.

### 졸/병
- [x] 자신의 진영 기준으로 `전`, `좌`, `우`로 한 칸 이동할 수 있다.
- [x] `후`으로는 이동할 수 없다.
- [x] `궁성 대각선` 위에 있을 경우, 자신의 진영 기준 전방에 해당하는 대각선 방향으로 한 칸 이동할 수 있다.

### 마
- [x] `전`/`후`/`좌`/`우`로 한 칸 이동한 뒤, 좌측 또는 우측 대각선 방향으로 한 칸 더 이동할 수 있다.
- [x] 이동 경로에 다른 기물이 있으면 이동할 수 없다.

### 상
- [x] `전`/`후`/`좌`/`우`로 한 칸 이동한 뒤, 같은 방향의 대각선으로 두 칸 더 이동할 수 있다.
- [x] 이동 경로에 다른 기물이 있으면 이동할 수 없다.

### 차
- [x] `전`, `후`, `좌`, `우` 방향으로 원하는 만큼 이동할 수 있다.
- [x] 이동 경로에 다른 기물이 있으면 이동할 수 없다.
- [x] `궁성 대각선`을 따라 기물이 없는 한 원하는 만큼 이동할 수 있다.

### 포
- [x] 다른 기물 하나를 정확히 하나 넘은 뒤, `전`/`후`/`좌`/`우` 방향으로 원하는 만큼 이동할 수 있다.
- [x] 넘는 기물은 포가 될 수 없다.
- [x] 이동 경로에는 넘는 기물 하나를 제외하고 다른 기물이 있으면 안 된다.
- [x] 도착지에 상대 포가 있더라도 잡을 수 없다.
- [x] `궁성 대각선` 위에 있을 경우, 대각선 경로에 포가 아닌 기물이 정확히 하나 있을 때 그 너머 칸으로 이동할 수 있다.

### 보드 초기화
- [x] 한나라 기물(궁 1, 졸/병 5, 사 2, 마 2, 상 2, 차 2, 포 2)을 초기화한다.
- [x] 초나라 기물(궁 1, 졸/병 5, 사 2, 마 2, 상 2, 차 2, 포 2)을 초기화한다.
- [x] 각 진영의 상차림을 반영하여 초기 배치를 구성한다.

### 보드 상태 관리
- [x] 장기판 위 기물의 위치를 관리한다.
- [x] 기물이 이동하면 기존 위치에서 제거하고 도착 위치로 옮긴다.
- [x] 상대 기물을 잡은 경우 보드에서 제거한다.

### 진영 및 턴 관리
- [x] 기물의 진영(한/초)을 구분할 수 있다.
- [x] 현재 턴이 아닌 진영의 기물은 이동할 수 없다.
- [x] 상태 패턴을 활용하여 현재 턴을 관리한다.

### 게임 종료
- [x] 궁이 잡히면 게임을 종료한다.
- [x] 게임 종료 후 승패를 판별할 수 있다.
  - [x] 궁을 잡은 진영이 승리한다.
  - [x] 장군 없이 종료되면 남은 기물 점수 합이 높은 진영이 승리한다.

### 점수 계산
- [x] 기물 종류에 따른 점수를 계산한다.
- [x] 현재 남아 있는 기물을 기준으로 각 진영의 점수를 계산할 수 있다.
- [x] 한라나에 무승부 방지를 위한 덤(1.5점)을 추가 부여한다.

### 위치 정보
- [x] 기물의 행과 열 정보를 관리한다.

### 공통 제약
- [x] 같은 진영의 기물은 공격할 수 없다.

### DB 적용
- [x] 애플리케이션을 재시작하더라도 이전 게임을 다시 시작할 수 있다.

### 선택 기능
- [x] 장기 게임방을 생성할 수 있다.
- [x] 생성된 장기 게임방에 입장할 수 있다.

### 출력
- [x] 현재 보드 상태를 출력한다.
- [x] 게임 종료와 승리 진영을 출력한다.
- [x] 턴이 끝나면 해당 턴의 점수를 출력한다.
