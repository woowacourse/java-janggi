# java-janggi

장기 미션 저장소

## 기능 요구 사항

### 장기판
- 장기판은 9x10의 격자로 구성되어 있다.
- 각 격자는 좌표로 표현되며, (1,1)부터 (9,10)까지 존재한다.
- 시작 시 기물을 올바른 위치에 초기화한다.
- 기물과 기물의 위치정보를 갖는다.
- 장기판은 기물의 이동과 상태를 관리한다.

### 기물
- 기물의 종류 (예: 궁, 사, 상, 마, 차, 포, 병)
- 기물의 진영
- 포인지 아닌지 여부
- 각 기물 별 이동 범위를 정의한다.

### 좌표
- 좌표는 x와 y로 구성된다.
- 좌표는 장기판의 격자 위치를 나타낸다.

### 이동 전략
- 각 기물 별 이동 가능 여부를 판단하는 전략을 구현한다.
- 이동 전략은 기물의 종류와 현재 위치, 도착 위치에 따라 다르게 적용된다.

### 게임 진행
- 플레이어는 번갈아 가며 기물을 이동시킨다.
- 플레이어한테 시작 좌표와 도착 좌표 정보를 받는다.
- 게임은 한 플레이어가 상대방의 궁을 잡으면 종료된다.

### 입력
- 각 플레이어는 턴마다 이동할 기물의 현재 좌표를 입력받는다. (예 : "2,3", "2,4")
- 각 플레이어는 이동할 기물의 도착 좌표를 입력받는다. (예 : "2,3", "2,4")
- 기물의 마상 배치를 입력한다. (예 : 마상상마, 상마상마)
- 움직일 기물의 좌표와 도착 좌표를 입력한다.
- 게임이 종료될 때까지 입력을 반복한다.

### 출력
- 각 턴마다 장기판의 상태를 출력한다.
- 게임이 종료되면 승자를 출력한다.

### 예외 처리
- 마상 배치가 올바르지 않은 경우 
- 숫자가 아닌 좌표를 입력한 경우
- 범위를 벗어난 좌표를 입력한 경우
- 시작 좌표에 기물이 없는 경우
- 도착 좌표로 이동 할 수 없는 경우
