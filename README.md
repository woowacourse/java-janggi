# java-janggi

장기 미션 저장소

version : 1.3 (사이클2 요구사항 추가)

# 시나리오

1. 한나라 사용자가 상차림을 선택한다.
2. 초나라 사용자가 상차림을 선택한다.
3. 초나라 시작
    1. 이동할 기물의 좌표를 입력한다.

       현재 보드를 보여준다.

       ex) 졸을 선택했습니다. 졸은 현재 (1,1)에 있습니다.

    2. 해당 기물이 이동할 수 있는 좌표를 보여준다.
        - 만약에 아무데도 이동 불가능하면 다시 돌아가서 선택하게 한다.
    3. 보여진 좌표 중 이동할 좌표를 입력한다.
        - 이동할 좌표를 입력해주세요.(예시: 3, 5)
    4. 해당 좌표로 이동한다.
    5. 왕이 살아있는지 확인한다.
        - 왕이 죽었다면 게임을 종료한다.
4. 턴을 바꾼다. (초-> 한, 한 -> 초)

# 도메인 구현 리스트

- **보드**
    - [x] 상차림은 마상마상으로 고정하여 초기화 한다. (추후 추가 예정)
    - [x]  기물을 이동시킨다.
    - [ ] 보드는 궁성을 가진다.
    - [ ] 현재 점수를 계산한다.
    - [ ] 게임이 끝났는지 판단한다.
- **좌표**
    - [x]  보드 내의 좌표 범위를 검증한다.
- **기물**
    - [x]  해당 기물은 팀과 기물 타입을 가진다.
        - [x]  PieceType(enum) 작성
        - [x]  팀 Team(enum) 작성
        - [x]  해당 기물의 이동 가능 여부를 판단한다
            -[x] 멱에 다른 기물이 있으면 안 되는 경우: 마, 상, 졸/병, 차, 장, 사
            -[x] 멱 사이에 하나의 기물이 있어야 하는 경우: 포
                - 그 기물이 포여서는 안 된다.
                - 이동하고자 하는 좌표 자체가 포 or 아군이면 안 된다.
            -[ ] 궁성 내라면 대각선이 원래 가능하던 마, 상을 제외한 나머지 기물들은 갈 수 있는 경로가 더 많아질 수 있다.
                - 왕, 사는 이미 대각선이 가능하게 해놨기 때문에 이동 경로가 연결된 점인지 확인
                - 차, 포는 연결된 부분 추가
                - 졸은 앞방향으로 연결된 부분 추가
- **규칙**
    - [x]  각 기물은 고유의 규칙을 가진다.
- **궁성**
    - [ ] 점들끼리 대각선으로 연결된 부분이 있다.
    - [x] 초나라 궁성과 한나라 궁성이 있다.
