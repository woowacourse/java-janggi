# java-janggi

## 1.1 보드 초기화

- [x] 보드는 9행 * 10열 크기이다. (x축은 가로, y축은 세로이다.)
    - [x] x좌표는 0 이상 8 이하의 범위를 가진다. (총 9칸)
    - [x] y좌표는 0 이상 9 이하의 범위를 가진다. (총 10칸)
    - [x] 보드의 범위를 벗어난 좌표에 접근할 경우, IllegalArgumentException을 발생시킨다.
- [x] 보드의 좌측 하단을 (0, 0)으로 정의한다.

-[ ] 보드를 초기화한다.
    - [ ] 상차림에 맞도록 기물을 배치한다.
        - [ ] 왼상차림 : 상마상마
        - [ ] 오른상차림 : 마상마상
        - [ ] 바깥상차림 : 마상상마
        - [ ] 안상차림 : 상마마상
