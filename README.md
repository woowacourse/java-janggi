# 기능 구현 목록

### 입력

- 선공/후공 닉네임
- 상, 마 배치 선택 (1 - 상마상마, 2 - 마상마상, 3 - 마상상마, 4 - 상마마상)
- 기물 선택
  - 출발 위치
- 기물 이동
  - 도착 위치

### 게임 매니저
- 게임 상태

### 보드
- 배치를 입력받은 정적 팩토리 메서드
- 기물 이동
- 기물 위치 저장

### 기물
- 이동 전략 저장

### 포지션
- 좌표 저장
- 좌푯값 검증
  - x: 1~9, y: 1~9, 0

### 전략
- 일반전략
  - 이동 가능한 방향을 하드코딩
- 차전략
  - 끝점을 받고 길목 리스트 반환
- 포전략
  - 이동 기준(포 제외 말 넘기)
  - 잡히는 기준(포는 못 잡음)

### 팀(enum)
- CHO, HAN

### 예외 상황
- 닉네임이 빈 문자열인 경우
- 닉네임 중복 입력

- 말 배치 입력에서 1~4 이외의 입력이 들어오는 경우

- 유효하지 않은 좌표(보드의 바깥쪽)
- 선택 좌표에
  - 기물이 없을 때
  - 상대편 기물이 있을 때
- 도착 좌표가 유효한 좌표가 아닐 때


### 출력
- 보드를 출력한다.
