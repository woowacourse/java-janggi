### 무엇을 개발하는가?

- 장기 게임 도메인을 개발한다.
    - 콘솔 기반 입력/출력을 통해 게임을 진행할 수 있다.

### 실행 방법

- 프로젝트 루트에서 아래 명령으로 컴파일한다.

```bash
./gradlew classes
```

- 컴파일 후 아래 명령으로 애플리케이션을 실행한다.

```bash
java -cp build/classes/java/main Application
```

- 장기판 출력은 콘솔 환경에서 확인하는 것을 권장한다.
    - IntelliJ Run 콘솔에서는 한자와 ANSI 색상 처리 방식 때문에 장기판 레이아웃이 일부 어긋나 보일 수 있다.
    - 터미널에서 직접 실행하면 장기판 정렬이 더 안정적으로 보인다.

### 게임 방법

- 출발지와 도착지 좌표를 `row,column` 형식으로 입력해 기물을 이동한다.
- 상대 왕을 잡으면 게임이 즉시 종료되고 승자를 출력한다.
- 출발지 또는 도착지 입력 단계에서 `종료`를 입력하면 현재 보드 점수를 기준으로 승패를 계산해 출력한 뒤 게임을 종료한다.

### 기능명세서

#### 위치

- [x] 기물의 위치정보를 관리할 수 있다.
    - [x] 행을 구현한다.
    - [x] 열을 구현한다.

#### 기물

- [x] 비어있는 칸을 구현한다.
- [x] 기물의 진영을 구현한다.
    - [x] 한나라인지 확인한다.
    - [x] 초나라인지 확인한다.
- [x] 같은 진영의 기물은 공격할 수 없다.
- [x] 궁의 이동을 구현한다.
    - [x] `상`,`하`,`좌`,`우`로 한 칸 이동한다.
- [x] 사의 이동을 구현한다.
    - [x] `상`,`하`,`좌`,`우`로 한 칸 이동한다.
- [x] 졸병의 이동을 구현한다.
    - [x] `상`,`좌`,`우`로 한 칸 이동한다.
- [x] 마의 이동을 구현한다.
    - [x] `상`/`하`/`좌`/`우`-`우대각선`으로 한 칸 이동한다.
    - [x] `상`/`하`/`좌`/`우`-`좌대각선`으로 한 칸 이동한다.
    - [x] 이동 경로에 다른 기물이 있으면 안 된다.
- [x] 상의 이동을 구현한다.
    - [x] `상`/`하`/`좌`/`우`-`우대각선`-`우대각선`으로 이동한다.
    - [x] `상`/`하`/`좌`/`우`-`좌대각선`-`좌대각선`으로 이동한다.
    - [x] 이동 경로에 다른 기물이 있으면 안 된다.
- [x] 차의 이동을 구현한다.
    - [x] `상`,`하`,`좌`,`우`로 n칸 이동한다.
    - [x] 이동 경로에 다른 기물이 있으면 안 된다.
- [x] 포의 이동을 구현한다.
    - [x] 기물 1개를 넘어서 `상`,`하`,`좌`,`우`로 n칸 이동한다.
    - [x] 이동 경로에 기물이 1개 있어야 한다.
    - [x] 이동 경로에 포가 있으면 안 된다.
    - [x] 도착지에 상대의 포가 있으면 안 된다.
- [x] 궁성 영역을 고려한 궁의 이동을 구현한다.
    - [x] 궁은 궁성 안에서 `상`,`하`,`좌`,`우`,`대각선`으로 한 칸 이동한다.
- [x] 궁성 영역을 고려한 사의 이동을 구현한다.
    - [x] 사는 궁성 안에서 `상`,`하`,`좌`,`우`,`대각선`으로 한 칸 이동한다.
- [x] 궁성 영역을 고려한 졸병의 이동을 구현한다.
    - [x] 졸/병은 궁성 내부 대각선 선분 위에서 대각선으로 이동할 수 있다.
    - [x] 졸/병은 각 진영 기준으로 후진할 수 없다.
- [x] 궁성 영역을 고려한 차의 이동을 구현한다.
    - [x] 차는 궁성 내부 선분과 대각선 선분을 따라 이동할 수 있다.
- [x] 궁성 영역을 고려한 포의 이동을 구현한다.
    - [x] 포는 궁성 내부 선분과 대각선 선분을 따라 이동할 수 있다.
    - [x] 포의 기존 이동 규칙은 그대로 유지한다.

#### 보드

- [x] 장기판 위 기물의 위치를 관리한다.
    - [x] 기물의 위치를 이동시킨다.
    - [x] 기물이 죽으면 제거한다.
- [x] 장기판 위 궁성 영역을 표현한다.
    - [x] 위 궁성과 아래 궁성의 위치를 구분할 수 있다.
    - [x] 궁성 내부의 대각선 선분을 판별할 수 있다.

#### 초기화

- [x] 기물의 위치를 초기화한다.
    - [x] 한나라의 궁 1, 졸/병 5, 사 2, 마 2, 상 2, 차 2, 포 2를 초기화한다.
    - [x] 초나라의 궁 1, 졸/병 5, 사 2, 마 2, 상 2, 차 2, 포 2를 초기화한다.
    - [x] 각 진영의 상차림을 구현한다.

#### 게임 진행

- [x] 현재 턴이 아닌 진영이 공격하는 경우를 예외 처리한다.
- [x] 왕이 잡히면 게임을 종료한다.
    - [x] 상대의 왕이 잡히면 승리한다.
    - [x] 게임이 종료되면 추가 이동을 진행하지 않는다.
- [x] 현재 남아 있는 기물의 점수를 계산할 수 있다.
    - [x] 차는 13점이다.
    - [x] 포는 7점이다.
    - [x] 마는 5점이다.
    - [x] 상은 3점이다.
    - [x] 사는 3점이다.
    - [x] 졸/병은 2점이다.
    - [x] 후수는 총점에 1.5점을 더한다.
- [x] 초 점수와 한 점수를 함께 관리할 수 있다.
- [x] 점수 비교로 승자를 판단할 수 있다.

#### 입출력

- [x] 사용자는 자신의 상차림을 선택할 수 있다.
- [x] 사용자는 이동할 기물의 출발지와 도착지를 입력할 수 있다.
- [x] 사용자는 종료 입력으로 현재 점수 기준 승패를 확인할 수 있다.
- [x] 이동 후 장기판 상태를 출력할 수 있다.
- [x] 궁성영역이 반영된 장기판 상태를 출력할 수 있다.
- [x] 게임 승패 결과를 출력할 수 있다.
    - [x] 왕이 잡혀 게임이 종료되면 승자를 출력한다.
    - [x] 게임 결과와 점수 결과를 함께 출력할 수 있다.

#### DB

- [ ] 애플리케이션을 재시작해도 마지막으로 진행 중이던 장기 게임을 이어서 시작할 수 있다.
- [ ] 이동이 성공하면 현재 게임 상태를 저장할 수 있다.
- [ ] 저장된 게임 상태를 조회해 장기판, 현재 턴, 게임 상태를 복원할 수 있다.

#### 영속화 규칙

- [ ] 도메인 객체는 저장 방식을 알지 않는다.
- [ ] 저장/조회 로직은 Repository를 통해 분리한다.
