## 구현할 기능 목록

### 입력 기능

- [x] 제대로 된 입력값이 아니라면, 재입력을 요청한다.
  - [x] 상차림을 입력받는다.
  - [x] 이동할 기물의 위치를 입력받는다.
  - [x] 기물을 이동시킬 위치를 입력받는다.

### 출력 기능

- [x] 게임 시작을 알린다.
- [x] 상차림 초기화 후 장기판의 상황을 출력한다.
- [x] 선택한 기물이 이동할 수 있는 지점을 모두 표시한다.
- [x] 기물 이동 후 장기판의 상황을 출력한다.
- [ ] 게임 종료시
  - [x] 승리 진영을 출력한다.
  - [x] 각 진영의 점수를 출력한다.

### 도메인 기능

- [x] 각 기물은 고유한 행마법에 의해 이동할 수 있어야 한다.
- [x] 적 기물이 있는 위치로 이동하면 해당 적 기물을 잡는다.
- [x] 본인 진영 기물만 움직일 수 있다.
- [x] 이동할 수 없는 지점으로 움직이려하면 예외를 던진다.
- [x] 각 진영은 교대로 기물을 이동한다.
- [x] 왕이 잡히면 게임이 끝난다.
- [ ] `궁`과 `사`는 궁성의 밖으로 이동할 수 없다.
- [ ] `상`과 `마`를 제외한 기물은 (본인의 행마법을 준수하는 것을 전제로) 궁성의 대각선을 타고 이동할 수 있다.
  - 예를 들어, `병/졸`은 대각선 방향으로 전진은 가능하지만 후진은 불가하다. `포`는 이동할 대각선 방향에 screen이 존재해야 한다. (...)
- [x] 점수 계산
  - [x] 게임이 종료되면, 남아 있는 기물에 대한 점수를 계산한다. 각 기물의 점수는 [장기 규칙](https://arc.net/l/quote/isyrogth)을 참고한다.
  - [x] 한(HAN, 漢) 진영은 1.5점의 보너스 점수를 받는다.

#### 기물 초기 위치

- [x] 시작 위치가 고정된 기물들은 게임 시작 시 정해진 위치에 배치되어야 한다.
- [x] `상`과 `마`는 지정한 순서에 따른 위치에 배치되어야 한다.

## 용어 사전

| 용어 (영문)                  | 설명                                                  |
|:-------------------------|:----------------------------------------------------|
| **Row**                  | 장기판의 가로 선 (행)                                       |
| **File**                 | 장기판의 세로 선 (열)                                       |
| **Intersection**         | 가로선과 세로선이 만나서 생기는 격자점. 기물이 위치할 수 있는 곳               |
| **Side**                 | 진영. 초(CHO)와 한(HAN)으로 나뉨                             |
| **Piece**                | 장기판 위에 놓이는 모든 기물의 총칭                                |
| **Chariot**              | 차 (車). 전후좌우로 장애물이 없는 한 끝까지 이동 가능                    |
| **Horse**                | 마 (馬). 날일자(日) 형태로 이동하며, 진행 방향의 첫 칸(멱)이 비어있어야 함      |
| **Elephant**             | 상 (象). 밭전자(田) 형태로 이동하며, 경로상의 모든 지점이 비어있어야 함         |
| **Guard**                | 사 (士). 궁성 안에서만 한 칸씩 이동하며 궁을 보좌함                     |
| **General**              | 궁 (장군). 궁성 안에서만 이동 가능한 왕                            |
| **Cannon**               | 포 (包). 다른 기물을 하나 넘어서 이동하거나 상대 기물을 취함                |
| **Soldier**              | 병(한), 졸(초). 앞으로 가거나 좌우로 한 칸씩 이동하며 후퇴 불가             |
| **Screen**               | `포`가 이동하거나 공격하기 위해 뛰어넘어야 하는 징검다리 기물                 |
| **Wing**                 | 진. 상과 마가 배치되는 지역으로 좌진(`Left`)과 우진(`Right`)으로 나뉨     |
| **Palace**               | 궁성. '궁'과 '사'가 위치하며 그 안에서만 움직일 수 있는 중앙 3x3 구역        |
| **XxxMovement**          | 특정 움직임을 나타내는 이동 방식                                  |
| **Path**                 | 기물이 목적지까지 도달하기 위해 거쳐야 하는 intersection들(= 목적지 + 경유지) |
| **Destination**          | `Path` 중 목적지                                        |
| **PassingIntersections** | `Path` 중 목적지를 제외한 나머지(= `경유지`)                      |
| **MoveRule**             | 이동 규칙                                               |
| **Capture**              | (어떤 기물을) 잡다, 죽이다                                    |
| **Point**                | 기물이 가지는 점수                                          |
