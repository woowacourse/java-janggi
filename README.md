# java-janggi

## 프로그램 흐름
1. **[출력] 장기 게임 시작 문구를 출력한다.**
2. **[중간 과정] DB에서 과거에 진행 중이던 게임이 존재하는지 조회한다.**

    a. **[입력] 존재하는 경우 게임 이어하기 여부를 입력받는다.(y/n)**<br>
        [예외처리] 입력값이 y/n이 아닐 경우 IllegalArgumentException 예외를 발생시킨다.

    b. **[출력] 이어할 경우 진행 중이던 게임 리스트를 출력한다.**

    c. **[입력] 이어할 게임 ID를 입력받는다.**<br>
        [예외처리] 게임이 존재하지 않을 경우 IllegalArgumentException 예외를 발생시킨다.

    d. **[중간 과정] DB에서 해당 게임의 마지막 턴 상태를 조회한다.**
3. **[중간 과정] 장기판을 초기화한다.**
4. **[출력] 초기화된 장기판을 출력한다.**
5. **[입력] 움직일 기물 좌표를 입력받는다.**

   [예외처리] 좌표를 쉼표로 구분하지 않았을 경우 IllegalArgumentException 예외를 발생시킨다.
   
   [예외처리] 좌표를 숫자로 입력하지 않았을 경우 IllegalArgumentException 예외를 발생시킨다.
   
   [예외처리] 장기판 범위 밖의 좌표를 입력했을 경우 IllegalArgumentException 예외를 발생시킨다.
   
   [예외처리] 입력한 좌표에 기물이 없을 경우 IllegalArgumentException 예외를 발생시킨다.
6. **[입력] 목적지 좌표를 입력받는다.**
   
   [예외처리] 좌표를 쉼표로 구분하지 않았을 경우 IllegalArgumentException 예외를 발생시킨다.
   
   [예외처리] 좌표를 숫자로 입력하지 않았을 경우 IllegalArgumentException 예외를 발생시킨다.
   
   [예외처리] 장기판 범위 밖의 좌표를 입력했을 경우 IllegalArgumentException 예외를 발생시킨다.
   
   [예외처리] 입력한 좌표 또는 이동 경로에 아군 기물이 존재할 경우 IllegalArgumentException 예외를 발생시킨다.
7. **[중간 과정] 기물을 이동시킨다.**
8. **[입력] 게임 중단 여부를 입력받는다.(y/n)**

    [예외처리] 입력값이 y/n이 아닐 경우 IllegalArgumentException 예외를 발생시킨다.
9. **[중간 과정] 게임을 중단할 경우 마지막 턴을 DB에 저장한다.**
10. **[중간 과정] 왕이 잡혔을 경우 게임을 종료시킨다.**
11. **[출력] 게임 결과를 출력한다.**
