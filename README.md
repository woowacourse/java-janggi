# java-janggi

장기 미션 저장소

### 기능
- [x] 사용자 마상 위치 입력 기능
- [x] 입력 재시도 로직 기능 구현
- [x] 진영별 마상 위치 출력 기능
- [x] 진영별 턴을 관리하는 상태 패턴 구현
- [x] 초기화한 장기판 도메인 생성
- [x] 초기 장기판 출력
- [x] 마상 관련 초기화 기능 구현
- [x] 움직일 기물 입력 기능
- [x] 선택한 기물의 좌표 출력 기능
- [x] 기물 이동 기능 구현
- [x] 포와 졸 이동 검증 로직 추가
- [x] 사용자 입력값 검증 기능 추가 (번호인지, 빈문자열은 아닌지 등)
- [x] 진영별 색상 출력 추가
- [x] 궁성 영역 규칙 추가
- [x] 왕이 잡힐 경우 게임 종료 로직 구현
- [x] 남아 있는 기물에 대한 점수 계산 기능

### 테스트

- [x] BoardTest 테스트 추가
