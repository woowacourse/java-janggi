### 무엇을 개발하는가?

- 장기판의 초기화 (각 진영은 상마 조합을 선택하여 상차림할 수 있다.)
- 기물의 이동 규칙을 구현한다.

### 기능명세서

- [x] 궁의 이동을 구현한다
    - [x] `상`,`하`,`좌`,`우`로 한 칸 이동한다.
- [x] 사의 이동을 구현한다
    - [x] `상`,`하`,`좌`,`우`로 한 칸 이동한다.
- [x] 졸병의 이동을 구현한다
    - [x] `상`,`좌`,`우`로 한 칸 이동한다.
- [x] 마의 이동을 구현한다
    - [x] `상`/`하`/`좌`/`우`-`우대각선`으로 한 칸 이동한다.
    - [x] `상`/`하`/`좌`/`우`-`좌대각선`으로 한 칸 이동한다.
    - [X] 이동 경로에 다른 기물이 있으면 안 된다.
- [x] 상의 이동을 구현한다
    - [x] `상`/`하`/`좌`/`우`-`우대각선`-`우대각선`으로 한 칸 이동한다.
    - [x] `상`/`하`/`좌`/`우`-`좌대각선`-`좌대각선`으로 한 칸 이동한다.
    - [X] 이동 경로에 다른 기물이 있으면 안 된다.
- [X] 차의 이동을 구현한다
    - [X] `상`,`하`,`좌`,`우`로 n칸 이동한다.
    - [X] 이동 경로에 다른 기물이 있으면 안 된다.
- [X] 포의 이동을 구현한다
    - [X] 기물 1개를 넘어서 `상`,`하`,`좌`,`우`로 n칸 이동한다.
    - [X] 이동 경로에 기물이 1개 있어야 한다.
    - [X] 이동 경로에 포가 있으면 안 된다.
    - [x] 도착지에 상대의 포가 있으면 안 된다.
    - [X] 이동 경로에 다른 기물이 있으면 안 된다.
- [x] 기물의 위치를 초기화한다.
    - [x] 한나라의 궁1 졸5 사2 마2 상2 차2 포2 를 초기화 한다.
    - [x] 초나라의 궁1 졸5 사2 마2 상2 차2 포2 를 초기화 한다.
    - [x] 각 진영의 상차림을 구현한다.
- [x] 장기판 위 기물의 위치를 관리한다.
    - [x] 기물이 죽으면 제거한다
    - [x] 기물의 위치를 이동시킨다
- [x] 기물의 진영을 구현한다.
    - [x] 한나라인지 확인한다.
    - [x] 초나라인지 확인한다.
- [x] 기물의 위치정보를 관리할 수 있다.
    - [x] 행을 구현한다.
    - [x] 열을 구현한다.
- [x] 같은 진영의 기물은 공격할 수 없다.
- [x] 현재 턴이 아닌 진영이 공격하는 경우를 예외 처리한다
  - [x] 상태패턴을 활용하여 현재 턴을 관리한다
- [x] 각 진영이 선택한 상차림으로 장기판을 초기화한다.
- [x] 보드를 출력한다.
