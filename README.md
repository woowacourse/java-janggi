### 마상 배치 선택하기
- [ ]1P, 2P 순서로 마상 배치를 선택한다
- [ ] 안내 메시지: `(1 or 2)P 마상 배치를 선택해주세요.`
- [ ] 안내 메시지: `1. 마상상마 2. 마상마상 3. 상마마상 4. 상마상마`
- [ ]  입력 형태: `1`, `2`, `3`, `4`

### 보드 초기화
- [ ] 선택한 마상 배치에 따라 기물을 배치한다.
- [ ]  기본 배치 (한국식 장기)
  - 장·將: 궁 중앙 뒷줄 (col 4, row 0/9)
  - 사·士: 장 바로 앞줄 궁 중앙 (col 4, row 1/8)
  - 차·車: 양 끝 (col 0·8, row 0/9)
  - 포·包: (col 1·7, row 2/7)
  - 졸·卒: 5개 (col 0·2·4·6·8, row 3/6)
  - 마·馬, 상·象: 마상 배치 선택에 따라 결정
