### 무엇을 개발하는가?

- 장기 게임 도메인을 개발한다.
    - 콘솔 기반 입력/출력을 통해 게임을 진행할 수 있다.
- 궁성 규칙(궁성 구간의 대각선, 궁성 구간에서 달라지는 이동 규칙)은 구현하지 않는다.
    - 사이클 2에서 구현한다.

### 실행 방법

- 프로젝트 루트에서 아래 명령으로 컴파일한다.

```bash
./gradlew classes
```

- 컴파일 후 아래 명령으로 애플리케이션을 실행한다.

```bash
java -cp build/classes/java/main Application
```

- 장기판 출력은 콘솔 환경에서 확인하는 것을 권장한다.
    - IntelliJ Run 콘솔에서는 한자와 ANSI 색상 처리 방식 때문에 장기판 레이아웃이 일부 어긋나 보일 수 있다.
    - 터미널에서 직접 실행하면 장기판 정렬이 더 안정적으로 보인다.

### 기능명세서

#### 위치

- [x] 기물의 위치정보를 관리할 수 있다.
    - [x] 행을 구현한다.
    - [x] 열을 구현한다.

#### 기물

- [x] 비어있는 칸을 구현한다.
- [x] 기물의 진영을 구현한다.
    - [x] 한나라인지 확인한다.
    - [x] 초나라인지 확인한다.
- [x] 같은 진영의 기물은 공격할 수 없다.
- [x] 궁의 이동을 구현한다.
    - [x] `상`,`하`,`좌`,`우`로 한 칸 이동한다.
- [x] 사의 이동을 구현한다.
    - [x] `상`,`하`,`좌`,`우`로 한 칸 이동한다.
- [x] 졸병의 이동을 구현한다.
    - [x] `상`,`좌`,`우`로 한 칸 이동한다.
- [x] 마의 이동을 구현한다.
    - [x] `상`/`하`/`좌`/`우`-`우대각선`으로 한 칸 이동한다.
    - [x] `상`/`하`/`좌`/`우`-`좌대각선`으로 한 칸 이동한다.
    - [x] 이동 경로에 다른 기물이 있으면 안 된다.
- [x] 상의 이동을 구현한다.
    - [x] `상`/`하`/`좌`/`우`-`우대각선`-`우대각선`으로 이동한다.
    - [x] `상`/`하`/`좌`/`우`-`좌대각선`-`좌대각선`으로 이동한다.
    - [x] 이동 경로에 다른 기물이 있으면 안 된다.
- [x] 차의 이동을 구현한다.
    - [x] `상`,`하`,`좌`,`우`로 n칸 이동한다.
    - [x] 이동 경로에 다른 기물이 있으면 안 된다.
- [x] 포의 이동을 구현한다.
    - [x] 기물 1개를 넘어서 `상`,`하`,`좌`,`우`로 n칸 이동한다.
    - [x] 이동 경로에 기물이 1개 있어야 한다.
    - [x] 이동 경로에 포가 있으면 안 된다.
    - [x] 도착지에 상대의 포가 있으면 안 된다.

#### 보드

- [x] 장기판 위 기물의 위치를 관리한다.
    - [x] 기물의 위치를 이동시킨다.
    - [x] 기물이 죽으면 제거한다.

#### 초기화

- [x] 기물의 위치를 초기화한다.
    - [x] 한나라의 궁 1, 졸/병 5, 사 2, 마 2, 상 2, 차 2, 포 2를 초기화한다.
    - [x] 초나라의 궁 1, 졸/병 5, 사 2, 마 2, 상 2, 차 2, 포 2를 초기화한다.
    - [x] 각 진영의 상차림을 구현한다.

#### 게임 진행

- [x] 현재 턴이 아닌 진영이 공격하는 경우를 예외 처리한다.

#### 입출력

- [x] 사용자는 자신의 상차림을 선택할 수 있다.
- [x] 사용자는 이동할 기물의 출발지와 도착지를 입력할 수 있다.
- [x] 이동 후 장기판 상태를 출력할 수 있다.
