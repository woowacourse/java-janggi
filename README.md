# java-janggi

장기 미션 저장소

#  사이클 1

## 기능 요구 사항

### 1. 게임 환경 설정 및 초기화

- [x]  **보드를 초기화한다.**
    - [x]  초(楚)와 한(漢)의 기물들을 정해진 시작 위치에 배치한다.
- [x]  **장기 게임을 시작한다.**
    - [x]  초나라부터 첫 턴을 시작한다.

### 2. 기물 이동 및 검증

- [x]  **사용자로부터 이동할 기물과 목적지 위치를 입력받는다.**
- [x]  **이동 가능 여부를 단계별로 검증한다.**
    - [x]  **선택 검증:** 선택한 위치에 내 기물이 존재하는지 확인한다.
    - [x]  **경로 검증:** 기물별 이동 규칙(행마법)에 따라 목적지까지 갈 수 있는 경로인지 확인한다.
        - *예외:* 이동 경로가 유효하지 않은 경우 `IllegalArgumentException` 발생
    - [x]  **장애물 검증:** 이동 경로상에 다른 기물이 가로막고 있는지 확인한다. (마, 상, 차 등)
        - *예외:* 경로에 기물이 있어 통과할 수 없는 경우 `IllegalArgumentException` 발생
    - [x]  **도착지 검증:** 목적지에 자신의 기물이 이미 있는지 확인한다.
        - *예외:* 도착지에 아군 기물이 있는 경우 `IllegalArgumentException` 발생

### 3. 이동 실행 및 전투

- [x]  **보드에서 기물을 실제로 이동시킨다.**
- [x]  **상대 기물을 처리한다.**
    - [x]  이동한 위치에 상대편 기물이 있으면, 해당 기물을 보드에서 제거(탈락)한다.

### 4. 턴 관리 및 게임 종료

- [x]  **턴을 교체한다.**
    - [x]  초나라 턴이 끝나면 한나라 턴으로, 한나라 턴이 끝나면 다시 초나라 턴으로 변경한다.
- [x]  **게임 종료 조건을 판단한다.**
    - [x]  한 팀이라도 모든 기물이 탈락하면 게임을 종료한다.
- [x]  **게임이 종료될 때까지 위 과정을 반복한다.**

# 사이클 2

## 기능 요구 사항

### 궁성 이동 규칙

- [x] 장(궁)과 사는 자신의 궁성 안에서만 궁성의 선을 따라 한 칸 이동한다.
    - [x] `IllegalArgumentException`: 원래 위치가 궁성 밖인 경우
    - [x] `IllegalArgumentException`: 이동할 위치가 궁성 밖인 경우
    - [x] `IllegalArgumentException`: 궁성의 선을 따르지 않는 이동인 경우
- [x] 병(졸)은 상대 궁성 안에 있을 경우 궁성의 대각선을 따라 전진 대각 이동이 가능하다.
    - [x] 원래 위치가 상대 궁성 안인지 확인한다.
    - [x] 이동할 위치가 궁성의 대각선 상에 있는지 확인한다.
    - [x] `IllegalArgumentException`: 허용되지 않는 방향으로 이동하는 경우
- [x] 차는 궁성의 간선을 따라 대각선으로 이동할 수 있다.
    - [x] 원래 위치와 이동할 위치가 동일 궁성의 간선 위에 있는지 확인한다.
    - [x] `IllegalArgumentException`: 궁성 간선을 따르지 않는 대각 이동인 경우
    - [x] `IllegalArgumentException`: 이동 경로에 장애물이 있는 경우
-  [x] 포는 하나의 기물어 넘으면 궁성의 간선을 따라 대각선으로 이동할 수 있다.
    - [x] 원래 위치와 이동할 위치가 동일 궁성의 간선 위에 있는지 확인한다.
    - [x] 이동 시 반드시 하나의 기물을 넘어야 한다.
    - [x] `IllegalArgumentException`: 궁성 간선을 따르지 않는 대각 이동인 경우
    - [x] `IllegalArgumentException`: 넘는 기물이 없는 경우
    - [x] `IllegalArgumentException`: 포를 넘는 경우

### 장군 (게임 종료)

- [x] 상대 장(궁)이 포획되면 해당 팀은 패배한다.
    - [x] 잡힌 기물이 장인지 확인한다.
    - [x] 장이 잡힌 경우 패배 팀을 결정한다.
    - [x] 게임을 종료한다.

### 점수 계산

- [x] 사용자가 무승부를 요청하면 점수로 승패를 결정한다.
    - [x] 무승부 요청을 입력받는다.
    - [x] 양 팀의 점수를 계산한다.
    - [x] 점수가 높은 팀을 승리 처리한다.
        - [x] 점수가 동일하면 한나라가 승리한다.
    - [x] 게임을 종료 상태로 변경한다.

### 게임 저장

- [x] 게임을 시작한다.
    - [x] 사용자가 플레이할 게임을 선택한다.
      - [x] 저장된 게임이 없으면 게임을 새로 생성한다.
      - [x] 저장된 게임이 있으면, 저장된 게임 중 하나를 선택한다.
        - [x] 저장된 게임 목록을 출력한다.
        - [x] 사용자에게 플레이할 게임을 입력받는다.
    - [x] 선택한 게임을 불러온다.
- [x] 게임을 진행한다.
    - [x] 기물을 움직여 게임 상태를 변경한다.
    - [x] 게임 종료 여부를 확인한다.
    - [x] 게임이 종료되지 않았으면 현재 게임 상태를 DB에 저장한다.
    - [x] 게임이 종료되었으면 게임을 종료한다.
- [x] 게임을 종료한다.
    - [x] DB에서 저장된 게임 데이터를 삭제한다.
