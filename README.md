### 기물 행마법

각 기물은 고유한 이동 규칙을 가지며, 경로에 따라 이동 가능 여부가 결정된다

- 차(Chariot) : 전후좌우 직선 이동 + 궁성 내 대각선 이동 (다른 기물을 넘을 수 없음)
- 포(Cannon) : 기물 하나를 넘어 전후좌우 직선 이동 + 포끼리는 넘거나 잡기 불가 + 궁성 내 대각선 이동
- 마(Horse) : 직선 한 칸 & 대각선 한 칸 이동 (다른 기물을 넘을 수 없음)
- 상(Elephant) : 직선 한 칸 & 대각선 두 칸 이동 (다른 기물을 넘을 수 없음)
- 졸/병(Soldier) : 전진 및 좌우 직선 한칸 이동 + 궁성 내 대각선 전진 이동 (후진 불가능)
- 사(Advisor) : 궁성 내에서만 선을 따라 한 칸 이동
- 궁(General) : 궁성 내에서만 선을 따라 한 칸 이동

## 게임 흐름

```
게임 시작
    ↓
진행 중인 게임 확인
  - 있음 → 이어하기 / 새 게임 선택
      - 이어하기 → 가장 최근 중단 게임 불러오기
      - 새 게임  → 기존 미완료 게임 종료 처리 후 새 게임 시작
  - 없음 → 새 게임 시작
    ↓
기물 차림 선택 (초 → 한 순서)
  - 왼차림 / 오른차림 / 안차림 / 바깥차림

----↓----

순서(초 → 한)에 따른 게임 진행
  - 기물 선택 → 이동 가능 좌표 표시 → 이동 or 취소(Q)
  - 매 턴 종료 후 점수 출력 및 DB 저장
    - 한(HAN) 보너스 +1.5점

----↓----

승패 판단
  - 상대 궁을 잡으면 승리
    
```

## 기능 목록

### 게임 시작

- 진행 중인 게임이 없으면 새 게임을 시작한다
- 진행 중인 게임이 있으면 이어하기 / 새 게임 시작을 선택한다
- 새 게임을 선택하면 기존 미완료 게임을 종료 처리한다
- 이어하기를 선택하면 가장 최근에 중단한 게임을 불러온다

### 기물 차림 선택

- 초(CHO), 한(HAN) 진영별로 차림을 선택한다 (왼상차림/오른상차림/안상차림/바깥상차림)

### 기물 이동

- 자신의 턴에 자신의 기물만 선택할 수 있다
- 기물 선택 시 이동 가능한 위치를 보드에 표시한다
- 이동 불가능한 좌표를 선택하면 예외가 발생한다
- 기물이 없는 위치는 선택할 수 없다.
- 기물 선택을 취소하려면 Q를 입력한다
- 위치 입력 형식은 `{한글}{숫자}` (예: 가0) 이다
    - X : 가 나 다 라 마 바 사 아 자 차
    - Y : 0~8

### 점수 계산

- 매 턴 종료 후 각 진영의 점수를 출력한다
- 점수는 보유 기물 점수의 합산으로 계산한다
- 한(HAN) 진영은 보너스 1.5점을 받는다

### 게임 종료

- 상대 진영의 궁을 잡으면 승리한다
- 게임 종료 시 DB에 완료 상태로 저장한다

### 게임 저장 / 이어하기

- 매 턴 종료 후 현재 보드 상태와 턴 정보를 DB에 저장한다
- 게임 이어하기 시 저장된 데이터로 보드 및 턴을 복원한다
- 미완료 게임 중 가장 최근 게임을 조회한다
