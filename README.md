# java-janggi

장기 미션 저장소

# 기능 목록

## 입력

- [x] 각 플레이어의 차림을 입력받는다.
- [x] 수행할 동작을 입력받는다.
- [x] 이동할 위치를 입력받는다.

## 출력

기

- [x] 장기판을 출력한다.
- [x] 상황에 따른 안내 문구를 출력한다.
- [ ] 게임 결과 승자를 출력한다.

## 기능

- [ ] 플레이어는 자신의 차례에 다음 항목중 하나를 수행할 수 있다.
    - [x] 자신의 기물을 움직일 수 있다.
    - [x] 자신의 턴을 넘길 수 있다.
    - [ ] 기권할 수 있다.
- [x] 기물이 움직일 수 없는 방법으로 입력할 수 없다.
- [x] 장기판의 범위를 벗어난 입력은 할 수 없다.
- [x] 왕이 잡히는 경우 왕을 잡은 플레이어의 승리로 게임이 종료된다.
- [ ] 자신의 기물 점수를 확인할 수 있다.
    - [ ] 후공인 한은 기물점수 1.5점을 받고 시작한다.
    - [ ] 기물 점수는 다음과 같다

        ```shell
        차: 13점
        포: 7점
        마: 5점
        상/사: 3점
        졸/병: 2점
        ```

## 기물

기물 움직임은 다음을 따른다

### 차 (Cha)

- [x] 가로 또는 세로 방향으로 원하는 칸 수만큼 이동한다.
    - [ ] 궁성 내부에 있는 경우, 선을 따라 대각선으로 이동할 수 있다.
- [x] 이동 경로에 아군 기물이 있으면, 해당 아군 기물 직전 칸까지만 이동한다.
- [x] 이동 경로에 상대 기물이 있으면, 해당 상대 기물 위치까지만 이동한다.

### 마 (Ma)

- [x] 직선 1칸 전진 후, 이동 방향의 대각선으로 1칸 이동한다.
- [x] 직선 1칸째 경로(목적지 미포함)에 기물이 있으면 이동할 수 없다.
- [x] 목적지에 아군 기물이 있으면 이동할 수 없다.
- [x] 목적지에 상대 기물이 있으면 해당 위치로 이동할 수 있다.

### 상 (Sang)

- [x] 직선 1칸 전진 후, 이동 방향의 대각선으로 2칸 이동한다.
- [x] 직선 1칸째 또는 대각선 1칸째 경로(목적지 미포함)에 기물이 있으면 이동할 수 없다.
- [x] 목적지에 아군 기물이 있으면 이동할 수 없다.
- [x] 목적지에 상대 기물이 있으면 해당 위치로 이동할 수 있다.

### 사 (Sa)

- [ ] 궁성 내부의 선을 따라 1칸 이동한다.
- [x] 목적지에 아군 기물이 있으면 이동할 수 없다.
- [x] 목적지에 상대 기물이 있으면 해당 위치로 이동할 수 있다.
- [ ] 궁성 밖으로 이동할 수 없다.

### 포 (Po)

- [x] 가로 또는 세로 방향으로 이동한다.
    - [ ] 궁성 내부에 있는 경우, 선을 따라 대각선으로도 이동할 수 있다.
- [x] 반드시 출발지와 목적지 사이의 기물(다리) 1개를 뛰어넘어야만 이동 및 공격이 가능하다.
- [x] 경로에 기물(다리)이 없거나 2개 이상이면 이동할 수 없다.
- [x] 목적지에 아군 기물이 있으면 이동할 수 없다.
- [x] 목적지에 상대 기물이 있으면 해당 위치로 이동할 수 있다.

### 졸 (Jol) / 병 (Byeong)

- [x] 앞으로 1칸, 또는 좌우로 1칸 이동한다.
    - [ ] 궁성 내부에 있는 경우, 선을 따라 전진 방향의 대각선으로 이동할 수 있다.
- [x] 목적지에 아군 기물이 있으면 이동할 수 없다.
- [x] 목적지에 상대 기물이 있으면 해당 위치로 이동할 수 있다.

### 장 (Jang)

- [ ] 궁성 내부의 선을 따라 1칸 이동한다.
- [x] 목적지에 상대 기물이 있으면 해당 위치로 이동할 수 있다.
- [ ] 궁성 밖으로 이동할 수 없다.

## 추가 구현 사항

- [x] 무승부를 판단할 수 있다
    - [x] 장과 장 사이에 아무 기물이 없이 한 턴이 지나면 무승부가 된다(빅장)
    - [x] 무승부가 되면 서로 남은 기물 점수로 승패를 판단한다.
