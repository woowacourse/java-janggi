# java-janggi

장기 미션 저장소

# 🎲️ 구현할 기능 목록

## 0. 게임 시작

- [x] 게임 시작 시, 데이터베이스에 진행 중인 게임이 있는지 확인한다.
    - [x] 진행 중인 게임이 있을 경우, 해당 게임을 불러온다.
    - [x] 진행 중인 게임이 없을 경우, 새로운 게임을 시작한다.

## 1. 보드 초기화

- [x] 10 X 9 배열을 사용하여 장기판을 생성한다.
- [x] 전체 기물을 올바른 위치에 초기화한다.
    - [x] 한나라 기물이 장기판의 윗부분에 위치한다.

## 1-1. 진영 선택

- [x] 초나라 플레이어가 선공권을 갖는다.

## 2. 보드 출력

- [x] 장기판을 출력한다.

## 3. 이동 기물 입력

- [x] 이동할 기물의 좌표를 입력받는다. (e.g. 3,4)
    - [x] 검증: 형식에 맞지 않는 좌표 입력은 예외를 발생한다.

## 3-1. 기물 이동

- [x] 검증: 장기판 범위를 초과한 좌표 입력은 예외를 발생한다.
- [x] 검증: 기물이 존재하지 않는 좌표 입력은 예외를 발생한다.
- [x] 검증: 상대 기물이 위치하는 좌표 입력은 예외를 발생한다.

- [x] 보드가 좌표를 입력 받아 해당 기물 객체를 반환한다.
- [x] 기물 이동 전략에 따라 이동 가능한 위치 좌표 목록을 계산한다.

## 3-2. 이동 가능 위치 좌표 목록 출력

- [x] 이동 가능 위치 좌표 목록을 번호를 매겨 출력한다.

## 3-3. 이동 위치 좌표 입력

- [x] 이동 가능 위치 좌표의 번호를 입력받는다.
    - [x] 검증: 존재하지 않는 번호 입력은 예외를 발생한다.

## 3-4. 이동 진행 보드 적용

- [x] 선택된 이동 위치 좌표에 기물을 이동시킨다.
- [x] 이동된 보드를 데이터베이스에 저장한다.

## 4. 승리 조건 확인

- [x] 이동된 보드에서 상대 장군이 잡혔는지 확인한다.
    - [x] 상대 장군이 잡혔을 경우, 현재 플레이어의 승리를 선언한다.
    - [x] 상대 장군이 잡히지 않았을 경우, 게임을 계속 진행한다.

## 5. 턴 교체

- [x] 플레이어 턴을 교체한다.
- [x] 교체된 턴을 데이터베이스에 저장한다.

2번으로 이동하여 게임을 반복한다.

## 6. 게임 종료

- [x] 게임 종료 시, 데이터베이스에 저장된 진행 중인 게임 데이터를 삭제한다.
- [ ] 게임 종료 시, 최종 승자와 각 진영의 최종 점수를 출력한다.
    - [ ] 각 진영의 최종 점수는 남아있는 기물의 점수 합으로 계산한다.
    - [ ] 한나라의 경우 무승부 방지를 위해 최종 점수에 1.5점을 추가한다.

# ♟️구현할 기물 기능 목록

## 졸

- [x] 상/좌/우 3가지 방향으로 1 칸 이동한다.
- [x] 이동 위치에 아군 기물이 있을 경우, 이동할 수 없다.
- [x] 궁성 안에서는 대각선을 따라 1칸 이동할 수 있다.
- [x] 아군 진영 방향으로는 이동할 수 없다.

## 차

- [x] 상/하/좌/우 4가지 방향으로 n 칸 이동 가능하다.
- [x] 다른 기물을 뛰어넘을 수 없다.
- [x] 이동 위치에 아군 기물이 있을 경우, 이동할 수 없다.
- [ ] 궁성 안에서는 대각선을 따라 이동할 수 있다.

## 마

- [x] 1차 이동: 상/하/좌/우 4가지 방향으로 1 칸 이동한다.
- [x] 2차 이동: 1차 이동 후, 해당 방향의 대각선 방향으로 1 칸 추가로 이동한다.
- [x] 1차 이동 위치에 다른 기물이 존재할 경우, 이동할 수 없다.
- [x] 2차 이동 위치에 아군 기물이 있을 경우, 이동할 수 없다.

## 상

- [x] 1차 이동: 상/하/좌/우 4가지 방향으로 1 칸 이동한다.
- [x] 2차 이동: 1차 이동 후, 해당 방향의 대각선 방향으로 1 칸 추가로 이동한다.
- [x] 3차 이동: 2차 이동 후, 해당 대각선 방향으로 1 칸 추가로 이동한다.
- [x] 1차 이동 위치에 다른 기물이 존재할 경우, 이동할 수 없다.
- [x] 2차 이동 위치에 다른 기물이 존재할 경우, 이동할 수 없다.
- [x] 3차 이동 위치에 아군 기물이 있을 경우, 이동할 수 없다.

## 포

- [x] 상/하/좌/우 4가지 방향으로 이동 가능하다.
- [x] 포를 제외한 다른 정확히 한 개의 기물을 뛰어넘은 후, n 칸 이동 가능하다.
- [x] 단, 포 끼리는 뛰어넘거나 잡아먹을 수 없다.
- [ ] 궁성 안에서는 대각선을 따라 이동할 수 있다.

## 사

- [x] 상/하/좌/우 4가지 방향으로 1 칸 이동한다.
- [x] 궁성 안에서는 대각선을 따라 1칸 이동할 수 있다.
- [x] 궁성 영역 밖으로 이동할 수 없다.

## 장

- [x] 상/하/좌/우 4가지 방향으로 1 칸 이동한다.
- [x] 궁성 안에서는 대각선을 따라 1칸 이동할 수 있다.
- [x] 궁성 영역 밖으로 이동할 수 없다.

# DB 구조

### 🧩 Domain 정의

#### SIDE_TYPE

* 타입: VARCHAR(3)
* 값:

    * HAN
    * CHU

#### PIECE_TYPE

* 타입: VARCHAR(10)
* 값:

    * KING
    * GUARD
    * ELEPHANT
    * HORSE
    * CHARIOT
    * CANNON
    * PAWN

---

### 🎮 game 테이블

| 컬럼명  | 타입        | 제약조건               | 설명    |
|------|-----------|--------------------|-------|
| id   | INTEGER   | PK, AUTO_INCREMENT | 게임 ID |
| turn | SIDE_TYPE | NOT NULL           | 현재 턴  |

---

### ♟️ piece 테이블

| 컬럼명        | 타입         | 제약조건     | 설명           |
|------------|------------|----------|--------------|
| col_num    | INTEGER    | PK       | 열 좌표         |
| row_num    | INTEGER    | PK       | 행 좌표         |
| piece_type | PIECE_TYPE | NOT NULL | 말 종류         |
| side       | SIDE_TYPE  | NOT NULL | 진영 (HAN/CHU) |

* 복합 PK: (col_num, row_num)
* 하나의 좌표에 하나의 말만 존재 가능
