## **🚀 기능 요구 사항**

### 1.1 **보드 초기화**

게임 시작 시 장기판과 전체 기물을 올바른 위치에 초기화한다.

- [ ] 장기판 초기화 전략을 번호로 입력받는다.
    - 상마마상, 상마상마, 마상마상, 마상상마
    - [ ] 사용자 입력값 유효성 검사
        - [ ] 공백인 경우 예외 처리
        - [ ] 숫자가 아닌 문자일 경우 예외 처리
        - [ ] 정수 범위를 벗어난 경우 예외 처리
    - [ ] 도메인 규칙 검증
        - [ ] 입력값이 선택지 범위에 포함되지 않는 경우 예외 처리
- [ ] 전략이 반영된 장기판 상태를 출력한다.
