## 1️⃣ 개요

### 기능 흐름

```
[앱 시작]
     │
     ▼
[게임방 선택]
  진행 중인 게임방 목록 출력
     │
     ├─ 1. 새 게임방 만들기 → 이름 입력 → DB 저장 후 입장
     └─ 2. 기존 게임방 입장 → 번호 선택 → 이전 상태 복원
     │
     ▼
[게임 시작 / 복원]
  DB에 저장된 상태가 있으면 해당 상태부터 이어서 진행
  없으면 새 게임 시작
     │
     ▼
[상차림 입력 - ReadyState]
  한(HAN) 상차림 선택 (1~4)
     │ 예외 → 재입력
     ▼
  초(CHO) 상차림 선택 (1~4)
     │ 예외 → 재입력
     ▼
[보드 초기화]
  입력된 상차림 기준으로 기물 배치
     │
     ▼
[게임 진행 - PlayingState] ◄────────────────┐
  현재 턴 출력 + 보드 출력                     │
     │                                    │
     ▼                                    │
  착수 명령어 입력 ({출발좌표} {도착좌표})        │
     │ 예외 → 재입력 (현재 턴 유지)            │
     ▼                                    │
  이동 유효성 검증                            │
    ├─ 출발 좌표에 기물 없음 → 예외             │
    ├─ 출발 좌표가 상대 기물 → 예외             │
    ├─ 도착 좌표에 아군 기물 → 예외             │
    └─ 기물 이동 규칙 위반 → 예외              │
     │ 성공                                │
     ▼                                    │
  기물 이동 (도착 좌표에 상대 기물 있으면 제거)     │
     │                                    │
     ▼                                    │
  DB에 게임 상태 저장 (매 수마다)               │
     │                                    │
     ▼                                    │
  턴 교체 (한 ↔ 초) ─────────────────────────┘
     │
     ▼ (게임 종료 조건 충족 시)
[게임 종료 - EndGameState]
  결과 출력 (승리 / 무승부)
  게임방 상태 FINISHED로 변경
```

## 2️⃣ 실행 방법

### 요구 사항

| 항목   | 버전               |
|--------|--------------------|
| Java   | 21                 |
| Gradle | 8.x (Wrapper 포함) |

> H2 임베디드 DB를 사용하므로 `./gradlew run` 로 실행합니다.

### 실행

```bash
./gradlew run
```

### 데이터 저장 위치

앱 실행 시 프로젝트 루트에 `janggi_db.mv.db` 파일이 자동 생성됩니다.

```
java-janggi/
├── janggi_db.mv.db   ← 게임 데이터 저장 파일 (자동 생성)
├── src/
└── build.gradle
```

앱을 재시작해도 이 파일을 통해 이전 게임 상태가 복원가능합니다.

### 초기화 (처음부터 다시 시작)

```bash
rm janggi_db.mv.db
./gradlew run
```

### 테스트 실행

```bash
./gradlew test
```

테스트는 인메모리 H2(`jdbc:h2:mem:...`)를 사용하고 있습니다.

## 3️⃣ 구현 기능 목록

### ✅ 1차 구현 기능 목록
#### 1.1단계: 보드 초기화
- [x] **1. [출력] 상차림 예시를 출력한다.**
- [x] **2. [입력] 상차림을 입력받는다.**
  - [x] [입력] 한의 상차림을 입력받는다.
    - [x] [예외 처리] 빈 입력일 경우 `IllegalArgumentException` 을 발생시키고, 재입력을 받는다.
    - [x] [예외 처리] 1~4 외의 문자를 입력한 경우 `IllegalArgumentException` 을 발생시키고, 재입력을 받는다.
  - [x] [입력] 초의 상차림을 입력받는다.
    - [x] [예외 처리] 빈 입력일 경우 `IllegalArgumentException` 을 발생시키고, 재입력을 받는다.
    - [x] [예외 처리] 1~4 외의 문자를 입력한 경우 `IllegalArgumentException` 을 발생시키고, 재입력을 받는다.
- [x] **3. [중간 과정] 입력받은 상차림을 기준으로 기물을 배치한다.**
- [x] **4. [출력] 현재 보드의 기물 배치를 출력한다.**

#### 1.2단계: 기물 이동
- [x] **5. [출력] 착수 명령어 형식과 현재 어느 팀의 턴인지를 출력한다.**
- [x] **6. [입력] 현재 턴의 진행자에게 착수 명령어를 입력받는다. (ex. '{출발좌표} {도착좌표}' 'A0 B1')**
  - [x] [예외 처리] 빈 입력일 경우 `IllegalArgumentException` 을 발생시키고, 재입력을 받는다.
  - [x] [예외 처리] 입력받은 값이 지정 형식인 '{출발좌표} {도착좌표}'가 아닐 경우 ` IllegalArgumentException` 을 발생시키고, 재입력을 받는다.
  - [x] [예외 처리] 입력받은 column 값이 A~I 범위의 값이 아닌 경우 `IllegalArgumentException` 을 발생시키고, 재입력을 받는다.
  - [x] [예외 처리] 입력받은 row 값이 0~9 범위의 값이 아닌 경우 `IllegalArgumentException` 을 발생시키고, 재입력을 받는다.
- [x] **7. [중간 과정] 사용자가 명령한 착수를 수행한다.**
  - [x] [예외 처리] 아래의 경우 왜 이동이 불가능한지 출력하고, 해당 플레이어의 턴으로 처음부터 재입력을 받는다.
    - [x] [중간 과정] 출발 좌표에 기물이 없는 경우
    - [x] [중간 과정] 출발 좌표에 상대 기물이 있는 경우
    - [x] [중간 과정] 각 기물 고유의 이동 규칙에 따라 이동이 불가능한 경우
    - [x] [중간 과정] 도착 좌표에 아군 기물이 있을 경우
  - [x] [중간 과정] 도착 좌표에 상대 기물이 있으면 없앤다.
  - [x] [중간 과정] 출발 좌표에 있던 기물을 도착 좌표로 옮긴다.
  - [x] [중간 과정] 턴을 넘긴다.

### ✅ 2차 구현 기능 목록
#### 2.1단계: 기물의 확장
- [x] **1. [중간 과정] 궁성 영역을 추가한다.**
  - 한(HAN) 궁성: row 0~2, col d~f
  - 초(CHO) 궁성: row 7~9, col d~f
- [x] **2. [중간 과정] 궁성 영역에 따른 이동 규칙을 추가한다.**
  - 궁성 내 장군(왕), 사, 차, 포의 대각선 이동 허용
  - 단, 궁성 내에서 대각선은 출발지던 목적지던 센터 포지션이 포함되어 있어야 한다는 사실을 수학적으로 풀면 됨.
  - [x] 장, 사 대각선 이동 수정
  - [x] 차, 포 대각선 이동 수정
- [x] **3. [중간 과정] 장군(Check)을 감지하고 선언한다.**
  - 상대 기물이 아군 장군을 공격 가능한 상태일 때 "[팀명] 장군!" 출력
- [x] **4. [중간 과정] 외통(Checkmate)을 감지하고 게임을 종료한다.**
  - 장군 상태에서 피할 수 있는 합법적인 수가 없을 때 → EndGameState 전환 후 승리 팀 출력
- [x] **5. [중간 과정] 왕(장군)을 제자리에 두면 한 수 쉬기로 인지하고 다음 턴으로 넘어간다.**
- [x] **6. [중간 과정] 빅장(Bikjang) 규칙을 적용한다.**
  - 두 장군이 같은 열에서 방해물 없이 마주보는 상태 감지
  - 해당 수를 두면 상대가 무승부 선언 또는 빅장을 깨는 수 선택
- [x] **7. [중간 과정] 무승부 조건을 감지하고 게임을 종료한다.**
  - 조건1: 양 팀 모두 합법적인 수가 없을 경우
  - 조건2: 양 팀 모두 기물이 부족하여 이길 수 없는 경우
  - → 기물 점수 합산 후 높은 쪽 승리
- [x] **8. [중간 과정] 기물 점수 시스템을 구현한다.**
  - 차(전차): 13점, 포: 7점, 마: 5점, 상: 3점, 사: 3점, 졸/병: 2점
  - 덤(Deom): 초(CHO) 선공 이점 보정 → 한(HAN) 측에 1.5점 가산
  - 초 기본 합계: 72점 / 한 기본 합계: 73.5점 (덤 포함)
- [x] **9. [중간 과정] EndGameState를 적용한다.**
  - 승리 / 무승부 결과 출력

#### 2.2단계: DB 적용
- [x] **0. [중간 과정] db setting을 만든다.**
- [x] **1. [중간 과정] 게임방을 만들고 입장할 수 있다.**
  - [x] 진행 중인 게임방 목록을 출력한다.
  - [x] 새 게임방을 생성할 수 있다.
  - [x] 기존 게임방에 입장할 수 있다.
- [x] **2. [중간 과정] 매 수마다 게임 상태를 DB에 저장한다.**
  - [x] 현재 상태(READY_HAN / READY_CHO / PLAYING / BIKJANG / END)를 저장한다.
  - [x] 현재 턴(HAN / CHO)을 저장한다.
  - [x] 상차림 선택 결과(한, 초)를 저장한다.
  - [x] 보드의 기물 전체 스냅샷을 저장한다.
- [x] **3. [중간 과정] 애플리케이션을 재시작해도 이전 게임을 이어서 플레이할 수 있다.**
  - [x] DB에 저장된 상태로 GameState를 복원한다.
  - [x] DB에 저장된 보드로 Board를 복원한다.
  - [x] 게임이 종료되면 게임방을 FINISHED 상태로 변경한다.

## 4️⃣ 입출력 요구 사항

### 실행 결과 예시

#### 게임방 선택

```
--- 장기 게임방 ---
진행 중인 게임방이 없습니다.

1. 새 게임방 만들기
2. 기존 게임방 입장
선택: 1

게임방 이름을 입력하세요: 내 게임방
'내 게임방' 게임방에 입장했습니다.
```

기존 게임방이 있을 경우:

```
--- 장기 게임방 ---
진행 중인 게임방:
  [1] 내 게임방
  [2] 연습용

1. 새 게임방 만들기
2. 기존 게임방 입장
선택: 2

입장할 게임방 번호를 입력하세요: 1
'내 게임방' 게임방에 입장했습니다.
```
