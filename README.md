# java-janggi

장기 미션 저장소

## 기능 요구 사항

### 1. 게임 환경 설정 및 초기화

- [ ]  **보드를 초기화한다.**
    - [ ]  초(楚)와 한(漢)의 기물들을 정해진 시작 위치에 배치한다.
- [ ]  **장기 게임을 시작한다.**
    - [ ]  초나라부터 첫 턴을 시작한다.

### 2. 기물 이동 및 검증

- [ ]  **사용자로부터 이동할 기물과 목적지 위치를 입력받는다.**
- [ ]  **이동 가능 여부를 단계별로 검증한다.**
    - [x]  **선택 검증:** 선택한 위치에 내 기물이 존재하는지 확인한다.
    - [x]  **경로 검증:** 기물별 이동 규칙(행마법)에 따라 목적지까지 갈 수 있는 경로인지 확인한다.
        - *예외:* 이동 경로가 유효하지 않은 경우 `IllegalArgumentException` 발생
    - [x]  **장애물 검증:** 이동 경로상에 다른 기물이 가로막고 있는지 확인한다. (마, 상, 차 등)
        - *예외:* 경로에 기물이 있어 통과할 수 없는 경우 `IllegalArgumentException` 발생
    - [ ]  **도착지 검증:** 목적지에 자신의 기물이 이미 있는지 확인한다.
        - *예외:* 도착지에 아군 기물이 있는 경우 `IllegalArgumentException` 발생

### 3. 이동 실행 및 전투

- [ ]  **보드에서 기물을 실제로 이동시킨다.**
- [ ]  **상대 기물을 처리한다.**
    - [ ]  이동한 위치에 상대편 기물이 있으면, 해당 기물을 보드에서 제거(탈락)한다.

### 4. 턴 관리 및 게임 종료

- [ ]  **턴을 교체한다.**
    - [ ]  초나라 턴이 끝나면 한나라 턴으로, 한나라 턴이 끝나면 다시 초나라 턴으로 변경한다.
- [ ]  **게임 종료 조건을 판단한다.**
    - [ ]  상대방의 '궁(王)'이 잡히거나, 더 이상 움직일 수 없는 상태가 되면 게임을 종료한다. (필요 시 점수 계산 로직 추가)
- [ ]  **게임이 종료될 때까지 위 과정을 반복한다.**
