# java-janggi

장기 미션 저장소

# 기능 목록

### 게임 상태
- [ ] 누구의 차례인지 알 수 있다.
- [ ] 게임이 진행 가능한지 알 수 있다.
- [ ] 게임 승패를 가릴 수 있다.

### 장기판
- [ ] 입력값이 장기판 범위 내인지 확인한다.
- [ ] 선택 가능한 기물인지 확인한다.
  - [ ] 빈 칸(기물)좌표가 아니어야 한다.
  - [ ] 턴에 맞는 기물 좌표여야 한다.
- [ ] 아군 기물들을 반환할 수 있다.
- [ ] 적군 기물들을 반환할 수 있다.
- [ ] 빈 칸(기물)들을 반환할 수 있다.

---

### 기물 -> 이동 전략, 기물 속성

### 기물 속성
- [x] 기물 이름 `ex. 車`
- [x] 소속팀

### 이동 전략 -> 목적지, 이동 경로
- [ ] 입력받은 위치 값(목적지)으로 이동 가능 여부를 반환할 수 있다.
  - [x] General(장군)
  - [ ] Guard(사)
  - [ ] Soldier(졸)
  - [ ] Horse(마)
  - [ ] Elephant(상)
  - [ ] Chariot(차)
  - [ ] Cannon(포)

- [ ] 입력받은 위치들(아군, 적군)이 이동경로에 포함되는지 여부를 반환할 수 있다.
  - 목적지만을 확인하는 기물(졸, 장, 사)는 `false` 반환

### 이동 경로
- [ ] 입력 받은 위치들이 이동경로에 포함되는지를 반환한다.
- [ ] 입력 받은 위치들이 이동경로에 몇개 포함되는지를 반환한다.
