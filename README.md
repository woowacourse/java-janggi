# java-janggi

장기 미션 저장소

## 실행 가이드

### 사전 준비

- Git이 설치되어 있어야 합니다.
- Docker Desktop이 설치되어 있고, 현재 켜져 있는(Running) 상태여야 합니다.

### 프로젝트 클론 및 디렉토리 이동

진행 중인 step2 브랜치만 지정해서 프로젝트를 클론하고, 해당 폴더로 이동합니다.

```Bash
git clone -b step2 https://github.com/alstj2384/java-janggi.git
cd java-janggi
````

### DB 서버 실행 (Docker)

Docker Compose를 이용하여 백그라운드에서 MySQL 데이터베이스 서버를 실행합니다.

```Bash
docker-compose up -d
```

### DB 서버 종료

사용이 종료되었다면, 아래 명령어를 통해 DB 서버를 내리시면 됩니다!

```Bash
docker-compose down
````

# 기능 목록

## 입력

- [x] 방 참가/생성 여부를 입력받는다.
- [x] 입장할 방 번호를 입력받는다.
- [x] 생성할 방 제목을 입력한다.
- [x] 각 플레이어의 차림을 입력받는다.
- [x] 수행할 동작을 입력받는다.
- [x] 이동할 위치를 입력받는다.

- [x] 장기판을 출력한다.
- [x] 상황에 따른 안내 문구를 출력한다.
- [x] 게임 결과 승자를 출력한다.

## 기능

- [x] 게임 방을 만들고 참여할 수 있다.
- [x] 프로그램이 종료되어도 게임의 상태가 저장된다.
- [x] 플레이어는 자신의 차례에 다음 항목중 하나를 수행할 수 있다.
    - [x] 자신의 기물을 움직일 수 있다.
    - [x] 자신의 턴을 넘길 수 있다.
- [x] 기물이 움직일 수 없는 방법으로 입력할 수 없다.
- [x] 장기판의 범위를 벗어난 입력은 할 수 없다.
- [x] 왕이 잡히는 경우 왕을 잡은 플레이어의 승리로 게임이 종료된다.
- [x] 자신의 기물 점수를 확인할 수 있다.
    - [x] 후공인 한은 기물점수 1.5점을 받고 시작한다.
    - [x] 기물 점수는 다음과 같다

        ```shell
        차: 13점
        포: 7점
        마: 5점
        상/사: 3점
        졸/병: 2점
        ```

## 기물

기물 움직임은 다음을 따른다

### 차 (Cha)

- [x] 가로 또는 세로 방향으로 원하는 칸 수만큼 이동한다.
    - [x] 궁성 내부에 있는 경우, 선을 따라 대각선으로 이동할 수 있다.
- [x] 이동 경로에 아군 기물이 있으면, 해당 아군 기물 직전 칸까지만 이동한다.
- [x] 이동 경로에 상대 기물이 있으면, 해당 상대 기물 위치까지만 이동한다.

### 마 (Ma)

- [x] 직선 1칸 전진 후, 이동 방향의 대각선으로 1칸 이동한다.
- [x] 직선 1칸째 경로(목적지 미포함)에 기물이 있으면 이동할 수 없다.
- [x] 목적지에 아군 기물이 있으면 이동할 수 없다.
- [x] 목적지에 상대 기물이 있으면 해당 위치로 이동할 수 있다.

### 상 (Sang)

- [x] 직선 1칸 전진 후, 이동 방향의 대각선으로 2칸 이동한다.
- [x] 직선 1칸째 또는 대각선 1칸째 경로(목적지 미포함)에 기물이 있으면 이동할 수 없다.
- [x] 목적지에 아군 기물이 있으면 이동할 수 없다.
- [x] 목적지에 상대 기물이 있으면 해당 위치로 이동할 수 있다.

### 사 (Sa)

- [x] 궁성 내부의 선을 따라 1칸 이동한다.
- [x] 목적지에 아군 기물이 있으면 이동할 수 없다.
- [x] 목적지에 상대 기물이 있으면 해당 위치로 이동할 수 있다.
- [x] 궁성 밖으로 이동할 수 없다.

### 포 (Po)

- [x] 가로 또는 세로 방향으로 이동한다.
    - [x] 궁성 내부에 있는 경우, 선을 따라 대각선으로도 이동할 수 있다.
- [x] 반드시 출발지와 목적지 사이의 기물(다리) 1개를 뛰어넘어야만 이동 및 공격이 가능하다.
- [x] 경로에 기물(다리)이 없거나 2개 이상이면 이동할 수 없다.
- [x] 목적지에 아군 기물이 있으면 이동할 수 없다.
- [x] 목적지에 상대 기물이 있으면 해당 위치로 이동할 수 있다.

### 졸 (Jol) / 병 (Byeong)

- [x] 앞으로 1칸, 또는 좌우로 1칸 이동한다.
    - [x] 궁성 내부에 있는 경우, 선을 따라 전진 방향의 대각선으로 이동할 수 있다.
- [x] 목적지에 아군 기물이 있으면 이동할 수 없다.
- [x] 목적지에 상대 기물이 있으면 해당 위치로 이동할 수 있다.

### 장 (Jang)

- [x] 궁성 내부의 선을 따라 1칸 이동한다.
- [x] 목적지에 상대 기물이 있으면 해당 위치로 이동할 수 있다.
- [x] 궁성 밖으로 이동할 수 없다.

## 추가 구현 사항

- [x] 무승부를 판단할 수 있다
    - [x] 장과 장 사이에 아무 기물이 없이 한 턴이 지나면 무승부가 된다(빅장)
    - [x] 무승부가 되면 서로 남은 기물 점수로 승패를 판단한다.
