## 2. 비즈니스 로직

-[ ] 보드 초기화 
  - [ ] 9x10 크기의 장기판을 생성
  - [ ] 장기판의 각 칸은 기물 또는 빈 칸 상태를 가짐
  - [ ]게임 시작 시 초와 한의 기물을 초기 위치에 배치

- [x] 좌표 관리
  - [x] 장기판의 좌표를 표현하는 객체
  - [x] 좌표가 장기판 범위를 벗어나면 예외를 발생시키도록 증

- [ ] 기물 생성
  - [ ] 차, 마, 상, 사, 장, 포, 졸, 빈 칸을 표현하는 객체
  - [ ] 각 기물은 자신의 진영, 이동방식, 이름을 가짐

- [ ] 보드 상태 조회
  - [ ] 특정 좌표의 기물 확인
  - [ ] 특정 좌표가 빈 칸인지 확인
  - [ ] 두 좌표 사이 경로에 기물이 있는지 확인

- [ ] 기물 이동 공통 규칙
  - [ ] 출발 위치에 기물이 존재해야 함
  - [ ] 도착 위치가 보드 범위 안이어야 함 
  - [ ] 같은 편 기물이 있는 칸으로는 이동할 수 없음
  - [ ] 제자리로는 갈 수 없음
  - [ ] 이동할 수 없는 경우 예외를 발생시킴(이후 재입력)
