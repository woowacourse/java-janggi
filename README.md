### 1-1. 보드 초기화

협력명: 장기판을 초기화 한다.

![img_1.png](img_1.png)

필요한 메시지(행동)
- 장기판을 초기화 하라
- 각 진영별 배치를 초기화 하라
- 진영별 배치를 선택하라
- 선택한 배치대로 기물들을 배치하라

#### 시나리오
1. 장기 게임을 초기화 한다. - JanggiGame
2. 진영별 배치를 선택한다. - Player
3. 진영에 맞는 기물 타입의 기물을 생성한다. - Piece
4. 각 진영별 기물 배치를 초기화한다. - Board

#### 각 메시지(행동)에 따른 책임을 부여한 객체
#### JanggiGame
- [x] 장기 게임을 초기화 한다.
- Board
- Players

#### Players
- [x] 각 플레이어별 
- 진영 side ENUM

#### Player
- [x] 진영별 배치를 선택한다.
- 진영 side ENUM
- Board

#### Board
- [x] 각 진영별 기물 배치를 초기화한다.
- Map<Position, Piece>
- MAX_ROW
- MIN_ROW
- MAX_COLUMN
- MIN_COLUMN

#### Piece
- [x] 기물 타입의 기물을 생성한다.
- 진영 side ENUM
- 기물 종류 type ENUM

#### Position
- row
- column

### 1-2. 기물 이동

협력명: 장기 기물을 이동한다.

![img.png](img.png)

### 이동 규칙

공통 규칙

- 보드판을 벗어날 수 없다.
- 본인 진영의 말만 이동 시킬 수 있다.
- 상대 진영의 말이 있는 칸으로 이동하면 포획할 수 있다.
- 본인 진영의 말이 있는 칸으로 이동할 수 없다.

시나리오

이동 실패 케이스

1. 1,9에 초 진영의 차가 배치되어 있다.
2. 1,9의 초 진영의 차를 1,10 위치로 이동시킨다.
3. 이동에 실패한다.

이동 실패 케이스

1. 초 플레이어의 턴이다.
2. 10,9에 한 진영의 차가 배치되어 있다.
3. 초 플레이어가 10,9의 말을 이동시킨다.
4. 이동에 실패한다.

이동 실패 케이스

1. 초 플레이어의 턴이다.
2. 1,9에 초 진영의 차, 4,9에 초 진영의 졸이 배치되어 있다.
3. 초 플레이어가 1,9의 차를 4,9의 위치로 이동시킨다.
4. 이동에 실패한다.

#### 졸

기본 조건: 
- 본인 진영 기준에서 앞으로 또는 옆으로 한칸 이동며 잡거나 이동할 수 있다.
- 뒤로는 이동 할 수 없다.

- 끝에 도달하면 옆으로만 이동할 수 있다.
- 적 진영 궁궐 안에서는 대각선으로 이동할 수 있다.

3. 5,1에 있던 한 진영의 졸이 죽는다.

### 차

기본 조건: 수평, 수직 직선으로만 이동하며 말을 잡을 수 있다.

- 궁권 안쪽에서는 대각선 방향으로 이동할 수 있다.

시나리오

이동 성공 케이스

1. 1,9에 초 진영의 차 4,9에 초 진영의 졸이 배치되어 있다.
2. 초 진영이 1,9의 차를 3,9 위치로 이동 시킨다.
3. 1,9에 있던 초 진영의 차가 3,9 위치로 이동된다.

포획 성공 케이스

3. 7,9에 있던 한 진영의 졸이 죽는다.

이동 실패 케이스

1. 1,9에 초 진영의 차 4,9에 초 진영의 졸이 배치되어 있다.
2. 초 진영이 1,9의 차를 6,9 위치로 이동 시킨다.
3. 이동에 실패한다.

이동 실패 케이스

### 마

기본 조건: 상하좌우 중 하나 이동 후 대각선 방향으로 한칸 바깥으로 이동한다.

- 첫번째 이동할 경로에 다른 말이 있으면 그 방향으로 이동할 수 없다.

### 상

기본 조건: 상하좌우 중 하나 이동 후 대각선 방향으로 두 칸 이동하여 2X3 직사각형 반대쪽 모서리에 도착한다.

- 중간에 있는 말에 막히면 점프할 수 없다.

### 사

기본 조건: 궁궐 내에서만 이동 가능 하며, 한 칸 씩 만 이동할 수 있다.

### 장

기본 조건: 궁궐 내에서만 이동 가능 하며, 한 칸 씩 만 이동할 수 있다.

- 상대 진영에게 잡히면 해당 진영은 게임을 패배한다.

### 포

기본 조건: 말을 하나 띄어넘어 잡거나 이동할 수 있다.

- 궁궐 안에서는 대각선으로 이동할 수 있다.
- 뛰어넘는 상대 말이 포가 될수 없다.
- 포끼리는 잡을 수 없다.

### 필요한 메시지 (행동)

- 플레이어들이 번갈아가며 각 기물들을 이동하라 JanggiGame
- 한쪽 진영의 말을 이동하라 (시작위치 → 도착위치) Player
- 기물을 이동시켜라 (시작위치 → 도착위치) Board
- 시작 위치의 기물을 도착위치로 움직일 수 있는지 알려줘 Piece
