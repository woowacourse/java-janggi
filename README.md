# java-janggi

장기 미션 저장소

## 1. 뷰
-[x] InputView
  - [x] 이동 / 턴 넘기기 / 기권 중 선택
    - [x] 이동 좌표 입력
- [x] OutputView
  - [X] 시작 문구
  - [X] 보드판 출력
  - [x] 승자 출력

## 2. 비즈니스 로직

-[x] 보드 초기화
    - [x] 10x9크기의 장기판을 생성
    - [x] 장기판의 각 칸은 기물 또는 빈 칸 상태를 가짐
    - [x] 게임 시작 시 초와 한의 기물을 초기 위치에 배치

- [x] 좌표 관리
    - [x] 장기판의 좌표를 표현하는 객체
    - [x] 좌표가 장기판 범위를 벗어나면 예외를 발생시키도록 증
- [x] 기물 생성
    - [x] 차, 마, 상, 사, 장, 포, 졸, 빈 칸을 표현하는 객체
    - [x] 각 기물은 다음 필드를 가짐
        - [x] 자신의 진영, 이름
        - [X] 이동 방식

- [x] 보드 상태 조회
    - [x] 특정 좌표의 기물 확인
    - [x] 특정 좌표가 빈 칸인지 확인

- [x] 기물 이동 공통 규칙
    - [x] 출발 위치에 현재 차례 플레이어 진영의 기물이 존재해야 함
    - [x] 도착 위치가 보드 범위 안이어야 함
    - [x] 같은 편 기물이 있는 칸으로는 이동할 수 없음
    - [x] 제자리로는 갈 수 없음

- [X] 기물별 이동 규칙
    - [x] 차
        - 같은 행 또는 같은 열로만 이동 가능
        - 경로 중간에 기물이 있으면 이동 불가
        - 궁성 안에서는 대각선으로도 이동 가능
    - [x] 마
        - 상 하 좌 우 한 칸 직선 이동 후 바깥 대각선 1칸 이동
        - 경로 중간에 기물이 있으면 이동 불가
    - [x] 상
        - 상 하 좌 우 한 칸 직선 이동 후 바깥 대각선 2칸 이동
        - 경로 중간에 기물이 있으면 이동 불가
    - [x] 사
        - 궁성 내에서 상 하 좌 우 대각선 한 칸 이동 가능
    - [x] 장
        - 궁성 내에서 상 하 좌 우 대각선 한 칸 이동 가능
    - [x] 포
        - 같은 행 또는 같은 열로만 이동 가능(궁성 내에서는 대각선 이동 가능)
        - 포를 제외한 하나의 기물을 넘어야 함
        - 포는 잡을 수 없음
    - [x] 쫄
        - 좌 우 이동이 가능
        - 진영에 따라 전진 방향이 정해짐
        - 진영에 따라 후진은 불가능

- [x] 승패 판단
  - [x] 누군가의 왕이 잡히는 경우 -> 왕이 남아있는 진영이 승리
  - [x] 두 진영이 연속으로 턴 넘기기를 하는 경우 -> 무승부 판정 후 점수 계산
  - [x] 한 플레이어가 기권하는 경우 -> 기권패

- [x] 게임 저장
  - [x] 정보 로딩
    - [x] 완료되지 않은 게임이 존재한다면, 기존 게임 정보를 불러오고 아니라면 새 게임을 시작함
  - [x] 정보 저장
    - [x] 게임 정보(게임 id, isFinished여부(승패가 정해져 완료된 게임인지), 마지막 현재 턴 정보)
    - [X] 기물 정보(게임 id(외래키), 행과 열, 기물 타입, 진영)
