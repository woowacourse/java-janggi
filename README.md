# java-janggi

장기 미션 저장소

# 기능 요구 사항

---

### 0. 장기 게임 선택

- [x]  사용자로부터 `새게임 시작`  혹은 `기존 게임 이어하기` 중 하나를 입력받는다.
- [x]  `새게임 열기`
    - [x]  사용자로부터 게임방 이름을 입력받는다.
    - [x]  새 게임을 시작한다.
- [x]  `기존 게임 참여`
    - [x]  사용자에게 현재 게임방 목록을 보여준다.
    - [x]  이 중 진행하고자 하는 게임방 이름을 입력받는다.
    - [x]  해당 게임을 이어서 진행한다.

### 1. 게임 환경 설정 및 초기화

- [x]  **보드를 초기화한다.**
    - [x]  초(楚)와 한(漢)의 기물들을 정해진 시작 위치에 배치한다.
- [x]  **장기 게임을 시작한다.**
    - [x]  초나라부터 첫 턴을 시작한다.
- [x]  궁성 영역을 정의한다.
    - [x]  초 궁성: 8~0행, 4~6열
    - [x]  한 궁성: 1~3행, 4~6열
- [x]  기물별 점수를 정의한다
    - [x]  차: 13점
    - [x]  포: 7점
    - [x]  마: 5점
    - [x]  상: 3점
    - [x]  사: 3점
    - [x]  병: 2점
    - [x]  장군: 0점
- [x]  게임 시작 전 나라별 점수를 보여준다.
    - [x]  후수인 한나라는 1.5점 덤 점수를 포함한다.

### 2. 기물 이동 및 검증

- [x]  **사용자로부터 이동할 기물과 목적지 위치를 입력받는다.**
- [x]  **이동 가능 여부를 단계별로 검증한다.**
    - [x]  **선택 검증:** 선택한 위치에 내 기물이 존재하는지 확인한다.
    - [x]  **경로 검증:** 기물별 이동 규칙(행마법)에 따라 목적지까지 갈 수 있는 경로인지 확인한다.
        - [x]  마: 한칸으로 전진 후, 대각선으로 한칸 이동한다.
        - [x]  상: 한칸으로 전진 후, 대각선으로 두칸 이동한다.
        - [x]  차: 수직 혹은 수평 방향으로 전진한다.
            - [x]  *궁성*: 궁성 내에서는 대각선으로 이동 가능하다.
        - [x]  포: 수직 혹은 수평으로 이동하되, 반드시 기물 하나를 뛰어넘어야 한다. 이때 뛰어넘는 기물과 도착지가 포이면 안된다.
            - [x]  *궁성*: 궁성 내에서는 대각선으로 이동 가능하되 이 역시 기물 1개를 넘어야 한다.
        - [x]  병: 적군을 향해 전진 한칸 혹은 좌우 한칸 이동한다.
            - [x]  *궁성*: 궁성 내에서는 대각선으로 전진 가능하다.
        - [x]  장군: 궁성 영역 안에서만 한칸 이동한다.
        - [x]  사: 궁성 영역 안에서만 한칸 이동한다.
        - *예외:* 이동 경로가 유효하지 않은 경우 `IllegalArgumentException` 발생
    - [x]  **장애물 검증:** 이동 경로상에 다른 기물이 가로막고 있는지 확인한다. (마, 상, 차 등)
        - *예외:* 경로에 기물이 있어 통과할 수 없는 경우 `IllegalArgumentException` 발생
    - [x]  **도착지 검증:** 목적지에 아군의 기물이 이미 있는지 확인한다.
        - *예외:* 도착지에 아군 기물이 있는 경우 `IllegalArgumentException` 발생

### 3. 이동 실행 및 전투

- [x]  **보드에서 기물을 실제로 이동시킨다.**
- [x]  **상대 기물을 처리한다.**
    - [x]  이동한 위치에 상대편 기물이 있으면, 해당 기물을 보드에서 제거(탈락)한다.

### 4. 턴 관리 및 게임 종료

- [x]  **턴을 교체한다.**
    - [x]  초나라 턴이 끝나면 한나라 턴으로, 한나라 턴이 끝나면 다시 초나라 턴으로 변경한다.
- [x]  **게임 종료 조건을 판단한다.**
    - [x]  왕을 잡은 쪽이 게임에서 이긴다.
- [x]  **게임이 종료될 때까지 위 과정을 반복한다.**
- [x] **게임이 종료되면 해당 게임 데이터는 자동 삭제된다.**
