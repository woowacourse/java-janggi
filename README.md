# java-janggi

장기 미션 저장소

---

### 플로우

1. 플레이어 2명의 이름을 입력 받는다. (초 → 한)
    1. 이름 규칙: (2~5자, 영어만)
    2. 초나라 먼저 입력받고, 한나라 입력
2. 각 플레이어의 상차림을 입력받는다. (초 → 한)

-- 각 플레이어 턴을 돌아가며 반복

1. 현재 장기판의 상태를 출력한다.
    1. 9 * 10 장기판 (열, 행)
    2. 초/한 구분은 색과 각 한자로 구분한다.
2. 각 플레이어의 타이머를 가동
3. 해당 턴 플레이어의 기물 목록을 출력한다.
    1. ex) 이동할 기물을 선택하세요: 1. 楚(2, 5)  2. 卒(2, 6)  3.  ~~~~
4. 이동할 기물의 번호를 입력받는다.
    1. 입력한 번호가 주어진 목록 내의 번호인지 검증한다.
5. 플레이어가 선택한 기물이 이동할 수 있는 좌표들의 번호를 출력한다.
    1. 선택한 기물을 움직였을 때 궁(왕)이 위험하면 선택 가능한 경로가 없으므로 기물 좌표를 재입력받는다.
        1. 즉, 장군일 때는 멍군이 가능한 기물을 선택한 것이 아니라면 5로 되돌아간다.
6. 좌표 목록 중 이동할 좌표의 번호를 입력받는다.
    1. 입력받은 번호가 이동할 수 있는 좌표 목록의 번호인지 검증한다.
7. 해당 좌표로 기물을 이동시킨다.
    1. 이동할 위치에 상대 말이 있으면, 해당 말을 잡는다.
8. 장군/외통수 판별
9. 타이머에 잔여 시간이 있는지 확인 후 종료 여부 판별
10. 해당 턴의 플레이어의 타이머를 중지하고, 턴을 종료한다.

-- 게임 종료

1. 상대 궁을 잡으면 게임 종료
2. 플레이어의 승패 결과를 출력한다.

### 우리가 정한 규칙

1. 플레이어마다 총 시간이 한정되어 있고, 타임 아웃 시 판정패

기물 종류 (초·한)

* 궁(楚·漢, General)
* 사(士·士, Guard)
* 마(马·馬, Horse)
* 상(象·象, Elephant)
* 졸, 병(卒·兵, Soldier)
* 포(包·包, Cannon)
* 차(车·車, Chariot)

    - [x] 출력: 초나라 플레이어의 이름을 입력하세요(2~5자, 영어만 사용):
    - [x] 출력: 한나라 플레이어의 이름을 입력하세요(2~5자, 영어만 사용):
    - [x] 각 이름의 규칙을 검증한다. (2~5자, 영어만)

    - [x] 초나라가 아래 좌표를 사용한다.

    - [x] 출력: 한나라 플레이어가 사용할 상차림 번호를 입력하세요

        - [x] 한나라 숫자 입력 및 번호 검증
    - [x] 입력받은 상차림으로 각 플레이어 상과 마 위치를 결정
- [ ] 각 플레이어 턴 진행
    - [ ] 현재 장기판을 출력한다.
        - [ ] 초나라(파란색), 한나라(빨간색), 좌표 출력
    - [ ] 타이머를 재개한다.
    - [ ] 플레이어의 기물들을 출력하는 기능
        - [ ] 출력: 이동할 기물을 선택하세요 1. 楚(2, 5)  2. 卒(2, 6)  3.  ~~~~

        - [ ] 제공된 기물 목록 번호 내의 범위인지 검증
    - [ ] 선택한 기물의 이동할 좌표를 선택하는 기능
        - [ ] 선택한 기물이 이동 가능한 좌표를 모두 계산한다.
            - [ ] 이동 가능한 좌표가 없으면 기물을 다시 선택하도록 돌아간다.
        - [ ] 출력: 이동할 좌표를 선택하세요: 1. (1, 2) 2. (2, 3) 3. ~~~
        - [ ] 이동할 좌표 번호 입력하는 기능
            - [ ] 입력한 번호가 목록 내에 있는지 검증
        - [ ] 해당 좌표로 이동
            - [ ] 만약 해당 좌표에 상대 기물이 있으면, 상대 기물 삭제

## 기물 이동 규칙

- [ ] 궁(楚·漢, General)
    - [ ] 궁성 안에서만 움직일 수 있음(사이클 2)
    - [x] 상하좌우 1칸
    - [ ] 각 궁 사이에 아무 기물도 없이 마주볼 수 없다.
- [ ]  사(士·士, Guard)
    - [ ] 궁성 안에서만 움직일 수 있음(사이클 2)
    - [x] 상하좌우 1칸
- [ ] 마(马·馬, Horse)
    - [x] 직선 1칸 + 대각선 1칸
    - [ ] 경로에 다른 기물이 존재하면 이동할 수 없음
- [ ] 상(象·象, Elephant)
    - [x] 직선 1칸 + 대각선 2칸
    - [ ] 경로에 다른 기물이 존재하면 이동할 수 없음
- [ ] 졸, 병(卒·兵, Soldier)
    - [x] 앞과 양 옆으로 1칸 이동
- [ ] 차(车·車, Chariot)
    - [x] 수직·수평으로 원하는 만큼 이동할 수 있음
    - [ ] 다른 말을 뛰어 넘을 수 없음
- [ ] 포(包·包, Cannon)
    - [x] 포는 기본적으로 수직·수평으로 이동 가능
        - [ ] 단, 첫 번째 기물 하나를 반드시 넘어야 하고, 그 뒤로 이어지는 빈칸들 중 하나로 이동할 수 있다.
        - [ ] 그 뒤로 처음 만나는 기물이 적군이면 그 기물을 잡을 수 있다.
        - [ ] 포는 포를 넘을 수 없다.
    - [ ] 포는 포를 공격할 수 없다.
