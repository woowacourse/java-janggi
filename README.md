## InputView

- [x] 차림을 입력받는다.
- [ ] 각 플레이어 턴의 행동을 입력받는다.
  ``` shell
  1. 이동 2. 턴 넘기기 3. 기권
  >> 1 
  ```
- [ ] 이동할 기물과 위치를 입력받는다.

## OutputView

- [x] 장기판을 출력한다.
- [ ] 선택에 따른 안내 문구를 출력한다.
- [ ] 승패를 출력한다.

# Controller

## JanggiController

- [ ] 장기 게임의 입출력과 실행 흐름을 관리한다.

## Game
